Four steps, and a person signs off each one

A4 Forge is AMC's guided build. Each step asks its questions in plain words, shows you how AMC understood your answers, and stops until the people you name approve the exact version in front of them.

  1. 1 Aspire

    Say what the agent is for

    Answer questions about the problem, who the agent serves, what success looks like and what it must never do. Start from your Industry Pack and AMC fills in the sector, a risk level and the rules to check, for you to correct.

    Who signs off One person who did not write the brief.

  2. 2 Assemble

    Build it

    Say what the agent may do on its own and what needs a person's yes, and choose its tools. AMC builds it in one closed session and records what ran. On the built-in stand-in model the record says so: the tools were seen working, the agent's behaviour was not judged.

    Who signs off Two people, neither of whom built it.

  3. 3 Adapt

    Fit it to your rules

    Say where the agent runs, whose data it touches and how long data is kept. AMC drafts the controls for those facts and lists which rules are met and which are still open, as a count and never a percentage. What you do not know stays unknown: AMC never guesses it.

    Who signs off Two people other than the one who asks. One of them is your workspace auditor.

  4. 4 Activate

    Release it

    AMC prepares a signed release package for Docker Compose or Helm. Your operator deploys it and signs a note that they did. AMC checks that the address answers, and records any rollback. AMC never deploys by itself.

    Who signs off Two people for the release, and two for completion.

    On a laptop the project ends after step 3. The release step works only when AMC itself runs under Docker Compose or Helm.

Trying it on your own? Start a practice project. You approve your own steps, and each one is marked self-approved in the record. It stops being practice as soon as a second person can sign in. Do not use a practice project for real work.

Starting from an Industry Pack? Then you need a second person. Every pack is rated high risk or above, so nobody approves their own step. As the workspace owner, choose Add a person in the Compass Console: it creates their account and shows their first password once.

Then it has to behave. AMC keeps watching

Building an agent is the start. Once it runs, AMC records what it does, applies your rules, and scores it from that record, so you are never taking the agent's word for it.

See what it did
AMC records each action it sees your agent take and signs the record. Its portable signed receipts say what was seen, which rules applied, which version and mode ran, and what could not be captured.
Stop what it should not do
Write rules for what the agent may do. In control mode AMC checks an action against your rules before it runs, and can stop it or ask a person first. By default AMC only records.
Know where it stands
The score comes from the record, not from a form: 244 questions, levels L0 to L5. What an agent says about itself counts for less than what AMC saw. A new agent starts at L0.
Hand over the evidence
Export a signed bundle and line it up with frameworks such as the EU AI Act, ISO 42001 and NIST AI RMF. Someone without your keys can check that nothing in it was changed.

READY setup is not COMPLETE. Setting AMC up is not the same as AMC having seen your agent work. amc connect --status and the console show four steps: agent connected, first action seen, first rule decision, first signed record. Only real, checked records of your agent at work complete them.

What AMC will not tell you

  • That your agent is safe, correct or lawful. AMC keeps the record of how the agent was built and what it did. People judge it.
  • That a signed record is true. A signature shows who wrote a record and that nobody has changed it since.
  • That a rule applies to you. Industry Pack content is AI-drafted and no lawyer has reviewed it. Check each rule with your own advisers.
  • That an outsider reviewed it. A second approver in your own workspace is separation of duties, not independent review.

Already have an agent?

You do not have to build with A4 Forge. Type amc and pick one of these. The menu lists only what can work on your machine.

Watch Claude Code or Codex

You stay signed in to Claude Code or Codex the way you already are. AMC never sees your password, token or plan. After you say yes, AMC adds a small hook to this project's settings and records each action the agent takes.

amc
# then choose: Watch Claude Code as it works

The menu offers this once Claude Code or Codex is installed and signed in; amc login status shows which. Observe mode only records. Control mode can also stop a Claude Code action before it runs. Codex is observe only. Sign-in and watch guide

Chat or run a task

AMC has its own agent. Chat with it in the terminal, or give it a task from the console. It uses only the tools you approve, and every turn is recorded. The demo uses a stand-in model with canned replies, so it needs no key.

amc
# then choose: Try a demo chat

A recorded session shows what was asked and what ran. It is not proof the answer is correct. Native task guide

Score an agent

Just show my score runs the full 244-question score in the terminal. Run it again after AMC has watched your agent work: that is when the score starts to mean something.

amc
# then choose: Just show my score

A signed score shows the report has not changed since it was written, not that it is true. Share a score outside your team only when its readiness says READY. Getting started

Get AMC

Everything on this page is in the current source build. It is not released yet (the source reports version 1.2.0). The one-line installers and npm still give the published 1.1.1 release, which has none of it.

Current, for macOS and Linux

Source build

git clone https://github.com/AgentMaturity/AgentMaturityCompass.git
cd AgentMaturityCompass
pnpm install --frozen-lockfile && pnpm run build && npm link
amc

Builds AMC from the repository and makes the amc command available with npm link. You get the menu, the A4 Forge preview, watching Claude Code and Codex, the native chat and tasks, the Compass Console and the free Industry Packs. Needs Node.js 20 or newer (tested on 22 and 24), pnpm and git. On Windows the source build has not been tested.

Published 1.1.1, older

Release installer

curl -fsSL https://agentmaturity.co/install.sh | sh
irm https://agentmaturity.co/install.ps1 | iex

Downloads the published 1.1.1 GitHub release, checks its SHA-256 checksum and installs it. npm also has 1.1.1. In 1.1.1, amc prints the full score. It has no menu, no A4 Forge and no Claude Code or Codex sign-in, and Industry Packs are still behind the earlier licence gate. The Homebrew tap is not public.

Download 1.1.1 from GitHub Releases. What is published where, with dates and evidence: publication-status.json.

Agent Maturity Compass Studio, the macOS app

The macOS app starts AMC and shows the Compass Console in its own window (a native WebKit window, no bundled browser). On first launch the macOS app asks whether to set up your own workspace or try the demo.

Your own workspace lives on your Mac. Its passphrase is kept in your macOS Keychain and the app signs you in as the owner, so every console control works. Studio > Try the Demo switches to the view-only demo, and Studio > Open My Workspace switches back. The app runs AMC on its own ports, so a terminal amc up keeps the defaults.

To get it today, build it from the source checkout with npm run package:desktop. The macOS app is ad-hoc signed, not notarized, so macOS may ask you to allow it in Privacy & Security the first time. No download of the current version is published; the 1.1.1 release archives on GitHub are the older version. AMC's desktop packages include macOS and Windows launcher apps. The Windows launcher opens the console in your browser and has not been run on Windows by the maintainers.

In one worked example, an agent's documentation scored 100 out of 100, and the same agent scored 16 when AMC looked at what it actually did. The 84 points between them are the gap, sometimes called documentation inflation. These numbers come from one worked example, the 84-point gap, not an average across agents.

Most tools score what you tell them. AMC scores what it sees. What an agent reports about itself counts for at most 0.4x weight; behaviour AMC recorded carries 1.0x weight.
