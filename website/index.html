agent maturity compass

See what your AI agent really does_

AMC watches Claude Code, Codex or your own agent at work on your machine, keeps a signed record of what it did, and scores it from that record.

Install, then type amc (current source build, macOS and Linux) 
$ git clone https://github.com/AgentMaturity/AgentMaturityCompass.git
$ cd AgentMaturityCompass
$ pnpm install --frozen-lockfile && pnpm run build && npm link
$ amc

Needs Node.js 22 or 24, pnpm and git. Free and open source (MIT); no AMC account. Other ways to install · Try it in your browser first

what you get in the first five minutes

Install, type amc, you are working_

  1. 1 · your folderA local workspace

    The first amc sets up .amc/ in the folder you are in, with its own signing keys. No AMC account and no cloud service.

  2. 2 · a working chatA demo chat, no key

    Try a demo chat talks to a built-in practice model that gives canned replies. You see what a recorded session looks like before you add a key.

  3. 3 · the consoleCompass Console in your browser

    Open the console starts AMC on your own machine (127.0.0.1) and opens the Compass Console. Its first screen has one button, which runs a sample task.

  4. 4 · an honest scoreA first score, empty for now

    A new folder scores L0 and says why: AMC has not seen your agent do anything yet. The score grows only from what AMC records.

then pick one

Three ways to start_

01 · watch my coding agent

Watch Claude Code or Codex

You stay signed in to Claude Code or Codex the way you already are (amc login status shows it). AMC never sees your password, token or plan. After you say yes, AMC adds a small hook to this project's settings. From then on it records each action the agent takes, and you can read them in the console.

$ amc login status
$ amc connect hooks install --provider claude-code --mode observe --agent default

Observe mode only records. Control mode can also stop a Claude Code action before it runs. It needs Claude Code settings with no enabled plugin and no other hook that can change a tool call. Codex is observe only.

sign-in and watch guide →
02 · run a task

Chat or run a task

AMC has its own agent. Chat with it in the terminal, or give it a task from the console's Native Tasks page. It uses only the tools you approve, and every turn is recorded. The demo uses a practice (stub) model; set a provider key such as ANTHROPIC_API_KEY to use a real one.

$ amc agent-loop chat --provider stub
$ amc agent-loop guide

A recorded session shows what was asked and what ran. It is not proof the answer is correct.

native task guide →
03 · score what I have

Score an agent

Just show my score runs the full 244-question score in the terminal. Run it again after AMC has watched your agent work: that is when the score starts to mean something. You can add any of the 41 free Industry Packs for your sector.

$ amc up
$ amc run
$ amc domain pack list

A signed score shows the report has not changed since it was written, not that it is true. Share a score outside your team only when its readiness says READY.

Which install gives you what_

Everything above is in the current source build. It is not released yet; the next release is 2.0.0. The one-line installers and npm still give the published 1.1.1 release, which has none of it.

$ git clone https://github.com/AgentMaturity/AgentMaturityCompass.git
$ cd AgentMaturityCompass
$ pnpm install --frozen-lockfile && pnpm run build && npm link

Builds AMC from the repository and makes the amc command available with npm link. You get the menu, watching Claude Code and Codex, the native chat and tasks, the Compass Console, free Industry Packs and the A4 Forge preview. Needs Node.js 22 or 24, pnpm and git. On Windows the source build has not been tested.

$ curl -fsSL https://agentmaturity.co/install.sh | sh
PS> irm https://agentmaturity.co/install.ps1 | iex

Downloads the published 1.1.1 GitHub release, checks its SHA-256 checksum and installs it. npm also has 1.1.1. In 1.1.1, amc prints the full score. It has no menu and no Claude Code or Codex sign-in, and Industry Packs are still behind the earlier licence gate. The Homebrew tap is not public.

macOS app

Agent Maturity Compass Studio

The macOS app starts AMC and shows the Compass Console in its own window (a native WebKit window, no bundled browser). On first launch the macOS app asks whether to set up your own workspace or try the demo.

Your own workspace lives on your Mac. Its passphrase is kept in your macOS Keychain and the app signs you in as the owner, so every console control works. Studio > Try the Demo switches to the view-only demo, and Studio > Open My Workspace switches back. The app runs AMC on its own ports, so a terminal amc up keeps the defaults.

To get it today, build it from the source checkout with npm run package:desktop. The macOS app is ad-hoc signed, not notarized, so macOS may ask you to allow it in Privacy & Security the first time. No download of the current version is published; the 1.1.1 release archives on GitHub are the older version. AMC's desktop packages include macOS and Windows launcher apps. The Windows launcher opens the console in your browser and has not been run on Windows by the maintainers.

how it works

More than a score.
A record you can check_

AMC records what your agent does and signs each record (a receipt), so a later change to it shows. Your score comes from those receipts. The same records let AMC check your rules, warn you when behaviour changes, show several agents together (a fleet), and line up with frameworks such as the EU AI Act. Setting AMC up is not the same as AMC having seen your agent work, and the console keeps the two apart.

set up vs. seenREADY setup is not COMPLETE

amc connect --status and the console show four steps: agent connected, first action seen, first rule decision, first signed record. Only real, checked records of your agent at work complete them.

check a ruleamc proof check

Checks a rule against the source text it comes from and saves the result as an amcproof file. When it cannot show the rule is correct, it reports unsupported. It never passes by default.

watch, or also blockWatch first, block if you choose

By default AMC only records the tool calls Claude Code, Codex and Gemini CLI make. For Claude Code or Gemini CLI you can turn on local control mode: AMC then checks each call against your rules before it runs, and signs its decision.

several agentsSee how your agents connect

For a system of several agents (a fleet), AMC gives an overview, checks how the agents hand work to each other, tracks service targets, and exports the map (the trust graph) before it scores them.

rules and attack testsAll in the free core

Rule decisions while the agent runs, snapshots of what it used, safe confirmation records, and 143 registered assurance packs (sets of attack tests) stay in the free core.

from brief to deployment · preview

A4 Forge (preview)_

A4 Forge takes one agent from a written brief to a recorded deployment in four stages: Aspire, Assemble, Adapt and Activate. No stage moves on until the people you name approve the exact version in front of them, and every step is written to a signed record you can verify yourself.

Preview in the current source build only (not in the published 1.1.1 release), off unless AMC_A4_PREVIEW=1. Every record is self-reported: a signature shows who wrote it and that it has not changed, never that it is true, and no A4 output says the agent is safe, correct or lawful. A second approver in the same workspace is separation of duties, not independent review. Not available yet: independently reviewed claims and a real deployment target.

01

Score

Point AMC at any agent. The default 244-question full score is based on what AMC recorded. The optional 264-question lifecycle set adds questions on running, proof, memory and several agents working together.

Fix

AMC shows the gaps that matter most and drafts the guardrail work for them. 143 registered assurance packs test your agent against prompt injection, data leaks, memory tampering, flattery and other attacks.

03

Ship and keep watching

Add a check to CI so a build fails when the score drops. Keep signed records on your machine. Produce the documents a review asks for under the EU AI Act, ISO 42001, NIST AI RMF, SOC 2, and OWASP LLM Top 10.

No AMC account and no cloud service: AMC runs on your machine and keeps its records there. The demo chat needs no key. To watch Claude Code or Codex you sign in to them with their own sign-in; to chat with a real model you set that provider's key, and your prompts then go to that provider.

Yes, and that is the point. A new agent that AMC has not seen do anything starts at L0, the lowest level. The score grows as AMC watches your agent actually work.

Every report carries a cryptographic signature. Change one character and verification fails, so someone who has your public key can check that the report is unchanged and who signed it. A signature shows who wrote it, not that it is true: the score is only as good as the evidence behind it. Try it on a real bundle we published.

In one worked example, an agent's documentation scored 100 out of 100, and the same agent scored 16 when AMC looked at what it actually did. The 84 points between them are the gap, sometimes called documentation inflation. AMC narrows it by scoring from recorded behaviour and signed records you can re-check, not from claims.

Most tools score what you tell them. AMC scores what it sees. What an agent reports about itself counts for at most 0.4x weight; behaviour AMC recorded carries 1.0x weight. AMC then shows the gaps, runs attack tests (assurance packs), and keeps records you can check later.
