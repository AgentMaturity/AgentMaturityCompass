AI agent evaluation decision guide

Choose the proof that matches the decision.

A model benchmark, an agent harness, a model card, an assurance report, an adversarial test, and observed production evidence answer different questions. AMC is one layer in that system, not a replacement for every other layer.

Start with the question

Seven evidence jobs, seven different outputs

These categories are complementary. Each card names the decision it is strongest at and the evidence unit it produces.

01

Build and operate an agent

Agent harness or SDK

Use a harness for interactive work, programmatic sessions, tools, providers, and workflow extension. Pi is one current example.

Evidence unit: session, event stream, or application behavior.

Source: SRC-PI
02

Compare model capabilities

Model and embedding benchmark

Use standardized scenarios, tasks, metrics, and result sets to compare foundation models or embedding systems.

Evidence unit: benchmark run and task-level result.

Sources: SRC-HELM, SRC-MTEB
03

Measure agent task performance

Agent task benchmark

Use controlled environments to compare how agents reason, decide, and act across defined tasks.

Evidence unit: benchmark trajectory and environment result.

Source: SRC-AGENTBENCH
04

Communicate model intent and limits

Model card

Use structured documentation to state intended uses, evaluation conditions, performance characteristics, and known limits.

Evidence unit: versioned model documentation.

Source: SRC-MODEL-CARDS
05

Assess service-organization controls

Organizational assurance report

Use an independent assurance engagement to understand controls relevant to security, availability, processing integrity, confidentiality, or privacy.

Evidence unit: scoped assurance report.

Source: SRC-SOC2
06

Discover adversarial failure modes

Expert testing and risk management

Use threat-informed testing and expert review to find failures, then combine findings with ongoing risk management and monitoring.

Evidence unit: test finding, scenario, mitigation, and retest result.

Source: SRC-NIST
07

Govern a deployed agent from observed evidence

AMC execution assurance

Use AMC to bind observed execution, evidence readiness, scoring, policy results, drift, and signed receipts to one agent lifecycle.

Evidence unit: signed lifecycle artifacts and claim-readiness state.

Source: SRC-AMC

Honest product boundary

Use these approaches together

AMC strengthens one part of an assurance program. It should not erase evidence that belongs to another part.

Integrity is not sufficiency

A signed artifact proves integrity, not evidence sufficiency. AMC reports INSUFFICIENT_EVIDENCE when the accepted evidence cannot support a claim.

Mapping is not certification

AMC can map evidence to control or regulatory questions. AMC does not certify legal compliance.

Execution proof has a scope

AMC does not replace model benchmarks, model cards, organizational assurance reports, or expert adversarial testing.
