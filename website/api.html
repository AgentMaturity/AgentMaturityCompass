API reference

AMC's REST API

Every route the AMC server, Studio, answers on your own computer or your own server. The version shown below is the API document's own version, not an AMC release.

Try a route with curl, not from this page.

Studio accepts calls only from its own address, so "Try it out" on this page is refused. On the computer where AMC runs, start it with amc up; it prints the Studio API address, by default http://127.0.0.1:3212/api. Then, for example:

curl http://127.0.0.1:3212/api/v1/health

It answers {"status":"ok","version":"1.2.0",…}. Most other routes need you to be signed in.
