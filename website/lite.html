Build an agent in four steps

A4 Forge is AMC's guided build, a preview that is on by default (starting AMC with AMC_A4_PREVIEW=0 turns it off). Each step asks plain questions and stops until the people you name approve it. Every step goes into a signed record.

  1. Aspire: say what the agent is for. One person who did not write the brief approves it.
  2. Assemble: build it. Two people, neither of whom built it, approve the result.
  3. Adapt: fit it to your rules. Two people other than the one who asks approve it, each a workspace owner or auditor.
  4. Activate: release it. AMC prepares a signed release package and your operator deploys it. On a laptop the project ends after Adapt.

Trying it alone? Start a practice project: you approve your own steps, and each one is marked self-approved. Starting from an Industry Pack? Then you need a second person, because every pack is rated high risk or above. How A4 Forge works

Install, then type amc

The current source build, for macOS and Linux. It needs git and Node.js 20, 22 or 24 (tested on 22 and 24; 25 and later lack Corepack, which the build needs).

curl -fsSL https://agentmaturity.co/install-source.sh | sh

amc shows one menu with what can work on your machine: Watch Claude Code as it works and Watch Codex as it works (each once you are signed in to it), Chat with a model (when a provider key is set), Try a demo chat (no account or key needed), Build an agent for my industry (A4 Forge preview), Open the console in my browser, and Just show my score.

It fetches AMC from GitHub, builds it on your computer and puts amc on your PATH (the list of folders your terminal looks in, so you can type amc in any folder); open a new terminal and type amc. If the command says the address is not found, build by hand as shown in Getting started. On Windows, irm https://agentmaturity.co/install-source.ps1 | iex does the same, but it has not been tested on a real Windows machine.

The source build is not released yet (the source reports version 1.2.0). The release installers (curl -fsSL https://agentmaturity.co/install.sh | sh, or irm https://agentmaturity.co/install.ps1 | iex on Windows) and npm give the older published 1.1.1 release. It has no menu, no A4 Forge, no Claude Code or Codex sign-in, and its Industry Packs are still behind the earlier licence gate.

On a first run a report can be signed and VALID and still say INSUFFICIENT_EVIDENCE. That is normal for a new folder. A signature shows who wrote a report and that it has not changed, not that it is true or that there is enough evidence behind it.

What you get in the first five minutes

A local workspace

The first amc sets up .amc/ in your folder with its own signing keys. No AMC account and no cloud service.

A demo chat, no key

In the amc menu, Try a demo chat talks to the built-in stand-in model, which gives canned replies. You see what a recorded session looks like before you add a key.

The Compass Console

Open the console starts AMC on your own machine (127.0.0.1) and opens its first screen, with one button that runs a sample task.

An honest first score

A new folder scores L0 and says why: AMC has not seen your agent do anything yet.

Already have an agent?

Watch my coding agent

AMC uses Claude Code's or Codex's own sign-in (amc login status) and never sees your password, token or plan. After you say yes, it adds a watch hook to the project and records each action. Observe mode only records. Control mode can also stop a Claude Code action before it runs; Codex is observe only.

Chat or run a task

Type amc and choose Try a demo chat, or run a task from the console. Set a provider key such as ANTHROPIC_API_KEY to use a real model; your prompts then go to that provider.

Score what I have

Just show my score runs the full 244-question score. Run it again after AMC has watched your agent. List the free Industry Packs with amc domain pack list; pack results are self-reported.

Who is this for?

Business leaders

Your company uses AI and your board asks whether it is safe. AMC gives a maturity level from L0 (Absent) to L5 (Optimizing), based on what the agent was seen to do, with safety results and evidence shown separately.

No-code users

Built a chatbot with Bubble, Zapier or Make? Use the playground to answer 15 questions in your browser. Its result is self-reported and illustrative.

Compliance officers

AMC maps evidence to relevant obligations and keeps maturity separate from legal status. AMC does not certify legal compliance.

Five trust dimensions

Strategic Agent Ops

Does the agent know its job, stay inside it, and leave a trail for each decision? 19 default questions.

Skills

Does it resist injected instructions, keep data from leaking, and use only the access it needs? 52 default questions.

Resilience

Does it fail safely, stop runaway loops, and recover from errors? 55 default questions.

Leadership & Autonomy

Can you see what it did and what it cost, and can a person step in? 23 default questions.

Questions

What is AMC?

Agent Maturity Compass is open-source software that helps you build an AI agent for regulated work, watches the agent work, keeps a signed record of what it did, and scores it from that record rather than from what it says about itself.

What is the 84-point gap?

In one worked example, an agent scored 100 out of 100 from keyword matching on its documentation and 16 when AMC looked at what it actually did. The 84 points between them are documentation inflation. It is one example, not an average.

Is AMC free?

Yes. MIT licensed and open source. The 41 Industry Packs are free in the current source build. Their content is experimental and AI-drafted; an AI agent checked the citations on 2026-11-16, not a qualified expert.

Do I need to code?

Someone has to install AMC once. After that the work happens in the Compass Console, in plain language. To look around with no install, use the playground to answer 15 questions in your browser.
