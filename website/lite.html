Install, then type amc

The current source build (macOS and Linux; needs Node.js 22 or 24, pnpm and git):

$ git clone https://github.com/AgentMaturity/AgentMaturityCompass.git
$ cd AgentMaturityCompass
$ pnpm install --frozen-lockfile && pnpm run build && npm link
$ amc

amc in a terminal shows one menu with what can work on your machine: Watch Claude Code as it works, Watch Codex as it works (each once you are signed in to it), Chat with a model (when a provider key is set), Try a demo chat (no account or key needed), Open the console in my browser, and Just show my score.

The source build is not released yet (the next release is 2.0.0). The one-line installers (curl -fsSL https://agentmaturity.co/install.sh | sh, or irm https://agentmaturity.co/install.ps1 | iex on Windows) and npm give the older published 1.1.1 release, which has no menu, no vendor sign-in, and Industry Packs still behind the earlier licence gate.

What you get in the first five minutes

A local workspace

The first amc sets up .amc/ in your folder with its own signing keys. No AMC account and no cloud service.

A demo chat, no key

Try a demo chat runs AMC's agent loop against a built-in stub model that gives canned replies, so you see a recorded session before you add a key.

The Compass Console

Open the console starts AMC on 127.0.0.1 and opens its first screen, with one button that runs a sample task.

An honest first score

A new folder scores L0 and says why: AMC has not seen your agent do anything yet.

Three ways to start

Watch my coding agent

AMC uses Claude Code's or Codex's own sign-in (amc login status) and never sees your password, token or plan. After you say yes, it adds a watch hook to the project and records each tool call. Observe mode only records; Claude Code control mode can deny a tool call, and needs Claude Code settings with no enabled plugin and no other hook that can change a tool call.

Run a task

Chat in the terminal (amc agent-loop chat --provider stub for the demo) or run a task from the console's Native Tasks page. Set a provider key such as ANTHROPIC_API_KEY to use a real model; your prompts then go to that provider.

Score what I have

Just show my score runs the full 244-question score. Run it again after AMC has watched your agent, and list the free Industry Packs with amc domain pack list. Pack results are self-reported.

Who is this for?

Business leaders

Your company uses AI and your board asks whether it is safe. AMC gives an evidence-backed maturity result from L0 (Absent) to L5 (Optimizing), with safety and proof shown separately.

No-code users

Built a chatbot with Bubble, Zapier or Make? Use the playground to answer 15 questions in your browser. Its result is self-reported and illustrative.

Compliance officers

AMC maps evidence to relevant obligations and keeps maturity separate from legal status. AMC does not certify legal compliance.

FAQ

What is AMC?

Agent Maturity Compass is open-source software that watches an AI agent work, keeps a signed record of what it did, and scores it from that execution evidence rather than from self-reported claims.

What is the 84-point gap?

In one worked example, an agent scored 100/100 from keyword matching on its documentation and 16/100 when AMC evaluated execution-verified evidence. That 84-point difference is documentation inflation. It is one example, not an average.

Is AMC free?

Yes. MIT licensed and open source. The 41 Industry Packs are free in the current source build.

Do I need to code?

No. Use the playground to answer 15 questions in your browser with no install. Scoring a real agent from evidence needs AMC installed.
