🧭 AMC Methodology

How Agent Maturity Compass decides how far you can trust an AI agent.

Current public methodology: 2026.10.08-r226 · released 2026-10-08

Core idea: what the agent did counts more than what it says

AMC scores agents on what they were seen doing, not on what they or their makers say. An agent that says "I'm secure" scores lower than one whose signed records show it acting securely.

The gap between what an agent claims and what its records support can be large. In one worked example it was 84 points.

Five Dimensions

AreaWhat it looks at
D1 — GovernanceIts written purpose, permissions, who must approve what, and rules for actions
D2 — CapabilityGetting tasks done, how long it works alone, tool use, handing work to others
D3 — Culture & AlignmentSafety, honesty, transparency, value coherence
D4 — ResilienceHandling errors, resisting attacks, noticing when its behavior changes
D5 — SkillsMemory, reasoning, knowing how sure it is, getting facts right

Maturity Scale (L0–L5)

LevelNameDescription
L0AbsentNo evidence collected
L1InitialSome intent, little operational evidence
L2DevelopingBasic governance, partial coverage
L3DefinedSystematic processes, evidence-backed
L4ManagedQuantitative measurement, continuous monitoring
L5OptimizingPredictive, self-improving, externally validated

How much each kind of record counts

TierWeightWhere it comes from
OBSERVED_HARDENED1.1×Attack tests that AMC runs and controls
OBSERVED1.0×Seen by AMC as the agent works
ATTESTED0.8×A signed statement from someone else (attestation)
SELF_REPORTED0.4×The agent's own claims (capped)

What AMC checks

244 default diagnostic questions across 5 layers, plus 20 optional lifecycle questions, free, for 264 questions total

143 registered assurance packs: sets of attack tests, including whether an agent fakes good behavior, holds back what it can do, or works against its instructions in secret

Scoring based on published research: answers backed by records count for more

8 compliance frameworks mapped: EU AI Act, GDPR, ISO 42001, SOC2, NIST AI RMF, HIPAA, PCI DSS, ISO 27001. AMC does not certify legal compliance.

41 industry domain packs: health, education, finance, mobility, governance, technology, environment. Their questions are experimental and AI-drafted until a named expert signs them.

Getting Started

curl -fsSL https://agentmaturity.co/install.sh | sh
amc                    # a menu in a terminal; "Just show my score" runs the full score
amc domain pack access # Industry Packs access; free in the current source build
amc assurance run --all # Red-team testing
amc proof check --manifest rules.json --input claim.json # Domain Proof Lane
amc comply report --framework EU_AI_ACT
