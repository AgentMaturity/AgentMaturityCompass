Getting started

Install AMC from source, run amc in a folder, and pick what to do from a short menu: build an agent for your industry, watch Claude Code or Codex, chat, or open the Compass Console.

Want a look first?

The playground runs in your browser with nothing to install. It is an illustration: its answers are your own, so its score is self-reported.

What you need

  • macOS or Linux. The source build has not been tested on Windows.
  • Node.js 20 or newer. AMC is tested on Node.js 22 and 24. Get Node.js.
  • pnpm and git. corepack enable turns on the pnpm that comes with Node.js.
node --version
git --version
corepack enable

Install AMC

The current version is the source build. It is not released yet, and the source reports version 1.2.0.

git clone https://github.com/AgentMaturity/AgentMaturityCompass.git
cd AgentMaturityCompass
pnpm install --frozen-lockfile && pnpm run build && npm link

npm link makes the amc command available everywhere. Check it:

amc --version
amc doctor

amc --version prints 1.2.0. In a folder AMC has not set up yet, amc doctor checks only the install and ends with "CLI install checks passed".

The one-line installers give an older version.

curl -fsSL https://agentmaturity.co/install.sh | sh, the PowerShell installer and npm all install the published 1.1.1 release. It has no menu, no A4 Forge and no Claude Code or Codex sign-in. Use the source build above to follow this guide.

Your first run

Make a folder for your work and run amc in it:

mkdir my-agent && cd my-agent
amc

AMC sets up the folder (it writes a .amc folder there) and asks what you want to do. The choices are:

  • Watch Claude Code or Codex. If one of them is installed, AMC offers to watch it, or to sign in to it first. Sign-in happens in the vendor's own tool; AMC never sees a password, token or plan. amc login status shows where each one stands.
  • Try a demo chat. No account or key needed. The replies come from the built-in stand-in model, which gives canned answers, so the chat says nothing about a real agent.
  • Build an agent for my industry. Starts A4 Forge (below) in the Compass Console.
  • Open the console in my browser. Starts AMC and opens the Compass Console.
  • Just show my score. Scores the folder from the records AMC has. In a new folder it is empty, and the menu says so.

Build an agent for regulated work

A4 Forge is AMC's guided build for one AI agent. It is a preview and on by default; starting AMC with AMC_A4_PREVIEW=0 turns it off. It takes the agent through four steps, Aspire, Assemble, Adapt and Activate, and the people you name approve each step. Each step goes into a signed record.

  • Start from an Industry Pack to get suggested rules and risks for your sector. Pack content is experimental and AI-drafted, not reviewed by a qualified expert, and not legal advice. amc domain pack list lists all 41.
  • A project started from a pack always needs a second person to approve.
  • To try it alone, start a practice project. Alone you can get as far as building in Assemble. Assemble's final approval, Adapt and Activate each need two approvers who did not write, build or ask for the step: three people in all.
  • On a laptop a project ends after Adapt. The release step needs AMC running under Docker Compose or Helm.

The A4 Forge page walks through each step and who signs it off.

Open the console

amc up
amc user init --username <you>   # new workspace only: the first console login (asks for a password)

amc up starts AMC and its console, called the Compass Console, and prints the address to open. The first time, it asks for a passphrase for the folder's vault, the store of keys AMC signs records with. Then sign in to the Compass Console at the address amc up printed. If the workspace already has logins, an owner adds yours with amc user add. amc down stops AMC again.

Your score

AMC scores an agent from records of what it did, in five areas, on a scale from L0 to L5. Today the highest level AMC gives is L2, and only behaviour AMC observed itself can reach it. What an agent or its makers report about themselves reaches L1 at most. A score is not a certificate and does not show that an agent meets any law. How the score works.

The eight tools

ToolWhat it does
ScoreScores an agent from records of what it did.
ShieldRuns attack tests against an agent, such as prompt injection and data leaks.
EnforceSets rules for what an agent may do, and asks a person to approve risky actions.
VaultKeeps the keys that sign AMC's records. A signature shows who wrote a record and that it is unchanged, not that it is true.
WatchFollows an agent over time and points out changes.
ComplyLines up records against frameworks such as the EU AI Act. It does not certify that you comply.
FleetCompares and governs several agents together.
PassportPacks an agent's score and records into a signed file others can check with AMC.
