AMC vs Promptfoo

Both tools help you test AI. They solve different problems. Here is how they differ.

⚖️ Fair comparison policy

Promptfoo is an established open-source tool for testing prompts and attacking AI apps. We respect their work. This page compares how the tools are built and what they are for.

Where Promptfoo is stronger

CapabilityDetails
Prompt-level evaluationBuilt for testing prompts across models. Comparison to known-good answers, A/B testing, moving to a new model. AMC does not test single prompts.
Target variety30+ target types including HTTP APIs, browser automation, direct model calls. Broader input surface than AMC's adapter approach.
Research datasets12 built-in attack datasets (HarmBench, BeaverTails, ToxicChat, etc.). AMC writes its own test cases instead of shipping outside datasets.
LLM-as-judgeA mature system that uses an LLM to grade answers. Useful when quality is a matter of judgment.
Community sizeA larger ecosystem with more third-party integrations.

Where AMC is stronger

CapabilityDetails
Maturity modelL0–L5 scores across 5 areas show what to improve next. Promptfoo gives pass/fail per test, with no overall level.
Evidence integritySignatures and hash chains (Ed25519 + Merkle trees) show if anyone changed a score. They show who signed it and that it is unchanged, not that it is true. Promptfoo results are unsigned JSON files.
Compliance mappingBuilds audit files for EU AI Act, ISO 42001, NIST AI RMF, SOC 2, and links results to legal requirements. It does not certify legal compliance. Promptfoo maps to OWASP only.
Agent governanceRules for actions, approval steps, time-limited access, spending limits, records of who handed work to whom. Promptfoo does not cover this.
Multi-agent fleetCompare agents, track trust handed between them, find the agents you run. Promptfoo tests one target at a time.
Industry packs41 industry question sets (healthcare/HIPAA, finance/MiFID II, education/FERPA, logistics/warehouse reliability), experimental and AI-drafted until a named expert signs them. Promptfoo has some industry plugins but fewer legal mappings.
Transparent proxyA gateway sees what the agent does without code changes. Those records count for more than self-reported test results.

When to use which

  • Use Promptfoo when you are tuning prompts, comparing model answers, or building tests for an LLM app that does not act on its own.
  • Use AMC when you need a signed record of what an agent did, files for a compliance review, and a level that shows what to fix.
  • Use both when you want prompt quality (Promptfoo) and an agent-level score (AMC). AMC can import Promptfoo eval results via amc eval import --format promptfoo.
