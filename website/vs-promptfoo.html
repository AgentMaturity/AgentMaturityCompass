AMC and Promptfoo

Both help you test AI. Promptfoo is built for testing prompts and model answers. AMC is built for building, running and checking an agent that acts at work, with a signed record of what it did.

How we wrote this

Promptfoo is an open-source tool, and we respect it. What this page says about AMC was checked against the AMC source. What it says about Promptfoo comes from its public description and was not re-checked for this page; read Promptfoo's own documentation before you decide.

When to use which

  • Use Promptfoo when you are tuning prompts, comparing model answers, or testing an LLM app that does not act on its own.
  • Use AMC when an agent acts at work and you need a signed record of what it did, people's sign-off on how it was built, and records to line up against a framework.
  • Use both when you want both. AMC can import Promptfoo results as self-reported records: amc eval import --format promptfoo --file results.json.
