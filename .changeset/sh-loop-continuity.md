Agent loop continuity (SH-LOOP): `amc agent-loop run --continue` and `amc agent-loop chat --continue` resume the most recent released native session for the agent in the workspace, and `amc session latest` shows which session that is and why others were passed over; a changed flag set is reported as `CONTINUE_CONFIGURATION_MISMATCH` naming the session. `--plan` runs a turn in plan mode: the root toolset is narrowed to the `READ_ONLY` action class (the same registry restriction a `--delegate-scope READ_ONLY` child runs under), `delegate`, `workflow` and `job_kill` are withheld by name, a deny-only guard covers tools mounted later, the model is told through the `context:plan-mode` runtime context, and the turn records a signed `NATIVE_PLAN_MODE` audit; the executing turn resumes the same session without `--plan`. `--stop max-turns:N|max-tokens:N|timeout-ms:N` bounds a run; a breach is a signed `loop/cancel` with cause `{kind:"limit", condition, bound}` and, inside a turn, the `turn/end` cancel cause; an unmeasured step fails the token limit closed. The composed turn handle gains `steer`, `queue` and `withdraw`, and `--interactive-steer` answers validated IPC steer and withdraw frames from a parent process with the signed inbox receipt. Instruction files now rank `CLAUDE.md` < `AMC.md` < `AGENTS.md` (with `AMC.local.md`), a project file's exact `@path` lines import workspace files up to four hops under the workspace's own confinement, and `amc agent-loop system-prompt instructions` lists what a native run loads. `amc session show` reports per-turn context occupancy (last and peak prompt tokens against the recorded window), and every step ends with a live `context` notification.
