Docs: a new threat model at `docs/security/THREAT_MODEL.md` names AMC's assets, actors and 15 channels, each with its enforcement point (file and symbol), evidence, status (`enforced`, `observed`, `advisory` or `none`), known bypasses and owning plan issue, plus STRIDE per channel, an 8-row failure policy and a draft mapping to the OWASP Top 10 for Agentic Applications (titles marked "re-verify"; experimental until reviewed). The same map is published as `docs/security/channel-map.json` with a JSON Schema, and `npm run check:threat-model` (run in CI) fails when a cited file, symbol or test no longer exists, an owner is not a plan key, or a failure row names neither a test nor an owner. The document records gaps it does not fix: MCP stdio server processes run unconfined with the user's rights, `src/enforce/egressProxy.ts` enforces nothing, `domainRules` and `bridgeResidencyHook` are unused, retention deletes without a legal-hold check, and `amc init --skip-vault` sets a time-based vault passphrase. The February 2026 threat model moves to `docs/archive/THREAT_MODEL-2026-02.md`, and `docs/THREAT_MODEL.md` now points to the new one. No runtime behaviour changes.
