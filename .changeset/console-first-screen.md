Compass Console: a first screen a new user understands in seconds. Home now shows one plain status line ("Demo workspace · No results yet · Records check out", or "Needs attention" with one link), one hero card with a single primary action ("Try a demo task" in the demo workspace, "Run a task" elsewhere, opening Native Tasks with a sample prompt), "Connect my agent", and a one-line progress summary whose steps fold open. Everything else (claim labels, quick links, counts, trend charts, developer details) sits under "More"; the trend charts appear only once a run exists. The nine status fields and their help moved under "Details" on every page; an active kill switch or freeze stays in sight. The "How AMC works" guide no longer opens by itself and is three steps. The top bar's "Open Standard" became the primary action, and the demo workspace has no "Sign out". The session line reads "Signed in as <name>" ("(view only)" for a viewer). Before the scripts run, pages say "Starting AMC…" instead of "Authentication required.", and Home and Login add a no-JavaScript line and, after a few seconds, a hint to reload or run `amc doctor`. Activation step 3 now names the control-mode command itself.
