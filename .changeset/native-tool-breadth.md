Adds five native tools that refuse by default and stay unreachable until a signed tools policy lists them: `web_fetch` and `web_search` (`NETWORK_EXTERNAL`), and `ask_user`, `todo` and `plan` (`READ_ONLY`). They are registered in the native toolset behind the prompt-injection, firewall, budget, network-egress, signed-allowlist and native-identity guards. The shipped default tools policy and `.amc/tools.yaml` do not list them, so in a default workspace the model is not offered them and every call is denied. `ask_user` also needs a composed answerer and `web_search` a composed search provider; AMC ships neither, so both refuse even when listed.

`web_fetch` and `web_search` reach only origins listed in their own signed `hostAllowlist` (a bare host grants `https` on port 443 only). Each request must then pass `decideEgress`, the egress decision the gateway and the native shell's proxy use: an unlisted name is never looked up, a listed name is resolved once, loopback, private, unique-local, link-local and other non-public addresses are refused unless that exact IP literal is listed, and the connection goes to the checked address. Each egress decision is written as a `NATIVE_WEB_EGRESS` audit row before it takes effect, and one that cannot be written is a refusal. Redirects are refused, not followed, so a site that only answers with a redirect must be fetched at its final URL. Fetched text and search results reach the model inside a random fence labelled untrusted data, not instructions and not evidence; receipts carry digests, never the content.

Every executed call of the five tools leaves one ledger receipt (`NATIVE_WEB_FETCH`, `NATIVE_WEB_SEARCH`, `NATIVE_ASK_USER`, `NATIVE_TODO` or `NATIVE_PLAN`) with the tool, session, agent and decision (`allow`, `deny` or `fail`, with the reason). A receipt that cannot be written fails the call. `ask_user` records the question and answer digests, never the answer text. `todo` and `plan` keep monitor-signed records under `.amc/native-tools/<sessionId>/`, record each record's digest in the session ledger before writing it, and refuse a record that does not match the latest receipt (`native tool record does not match the session ledger`), so an older signed record put back in place is refused.
