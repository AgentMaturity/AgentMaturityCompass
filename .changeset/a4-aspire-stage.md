A4 Aspire runs AMC's own producers, behind the A4 preview (`AMC_A4_PREVIEW=1`), offline and with no provider key. Aspire asks 14 questions (`agent`, `problem`, `audience`, `currentWorkflow`, `expertise`, `goals`, `successMetrics`, `constraints`, `forbiddenActions`, `riskTier`, `markets`, `stations`, `governance`, `archetypeInterest`); `stations` depends on `markets`, and `governance` on `riskTier` and `markets`, so changing the markets answer marks only those two answers for confirming (readiness `ask_complete` lists them as `ANSWER_STALE:<id>`) and Propose refuses with `A4_NOT_READY` until they are confirmed. Understand runs the existing detectors (framework and instruction-source file scans, the agent's context graph and config, the workspace's agents, station classification with its packs, matching archetypes by shared words, register entries with their `verified` flags as recorded) and records each as a self-reported stage output (implementation lane for workspace facts, recommendation lane for classifications), plus a reflection of the answers with assumptions and unknowns; it pre-fills unanswered questions from the existing agent config, context graph and project profile as `source: "inferred"` answers for the member to confirm. Explain renders the same facts at the novice, practitioner or expert level and keeps all three. Propose builds the brief from the answers: a context graph that `validateContextGraph` accepts, a misuse and failure-modes section, a typed multi-agent graph sketch, PMF hypotheses that stay `proposed` with `verdict: null`, at least two alternatives (archetype alternatives carry `previewArchetypeApply`'s context diff when the agent already has a context graph), a learning plan, a quality specification whose targets default to `measure: "not instrumented"`, and a value contract draft (not applied). Members may edit the hypotheses, learning plan, quality specification and misuse section; any other changed part is refused with `INPUT_INVALID`. Every Aspire output is `self_reported` with `result: not_evaluated`, its claim boundary reads "A brief is a statement of intent; no outcome is claimed.", and no Aspire output names a maturity level.

After the direction gate is consumed, Build writes `context-graph.json` with the same writer `initWorkspace` uses, scaffolds a new agent (a `local_openai` placeholder upstream with no key) or re-saves an existing agent's signed config and re-signs its default target profile with the new `contextGraphHash`, initialises the outcome contract when there is none and writes the Enforce resource manifest; each write is a self-reported implementation ref with its file's sha256. The typed graph stays a draft in the specification: Enforce's manifest writer refuses every workspace that holds `.amc/fleet/typed-graphs/latest.json`, so Build does not create that file. A manifest Enforce refuses is recorded and shows `manifest_active` BLOCKED (`ENFORCE_MANIFEST_REFUSED`). Review checks that the written context graph validates and matches the build and the signed target profile, runs the doctor's checks with their first-run fixes, checks the brief is complete, records the agent config's signature check as an integrity self-check (`SELF_CHECK`, `UNANCHORED`), and marks the review `not_evaluated` with `NO_RUNTIME_OBSERVATION_AT_ASPIRE`. Aspire readiness gains `understanding_confirmed`, `ask_complete`, `alternatives_present`, `hypotheses_present`, `learning_plan_present`, `quality_spec_complete`, `risk_section_present`, `brief_valid`, `context_graph_written`, `agent_config_signed` and `manifest_active`, plus one optional `hypothesis.<id>` item per hypothesis. Hypotheses live only in the revision, never in the decision-receipt files a full score run marks observed. Every revision now binds the agent's `brief.contextGraphSha256` and `brief.agentConfigSha256` as they are when it is recorded, so a context graph or agent config edited outside A4 after a gate is requested is refused at decide and complete with `RESOURCE_DRIFTED`.

The stage routes take `content` as optional where a stage has producers: `understand`, `explain`, `build` and `review` run AMC's producer, and any `content` sent is recorded beside it as the member's own statement. A stage without producers still requires `content` (400 `INPUT_INVALID`). Studio's Aspire view adds Brief, Solution sketch, Hypotheses (not observed), Learning plan, Quality specification and Alternatives cards, lists the answers to confirm, and shows what AMC understood and the explanation at each level. The completion effect that would apply the value contract and the quality-spec outcome targets is not part of this change. The ten-minute keyless first run has not been measured.
