Breaking: domain assessment, the path-based EU AI Act, ISO 42001 and OWASP LLM scorers, gaming resistance and industry benchmarks now report "not evaluated"; `--example` shows labelled synthetic output.

- `amc domain assess`, `gaps`, `report` and `roadmap` no longer derive scores, levels, gaps or a "Certification Readiness" line from a hash of the agent id. The base part reads the agent's latest sealed diagnostic run; the domain-rubric questions have no evidence source, so the result is not evaluated with its reasons. `--json` returns `status`, `reasons`, `claimKind` and `statusDimensions` (a changed shape). The commands exit 0 for not evaluated and 1 for bad arguments.
- `amc domain assurance` no longer grades a canned reply and never prints "all checks passed". It invokes no agent, so every scenario is not evaluated; an unregistered pack is a not-evaluated row naming its id. Use `amc assurance run` against a real agent for observed results.
- `--example` on those five commands prints illustrative values between two `SYNTHETIC EXAMPLE` banners, carries claim kind `synthetic_example`, stamps the banner into any `--output` file and writes nothing under `.amc/`. `amc certify`, `amc assurance cert-issue`, `amc bundle export`, `amc attest`, `amc passport create`, `amc audit binder create` and `amc notary sign` refuse a `synthetic_example` result; `amc notary sign` also refuses a text or Markdown file carrying the banner line, such as the report `--example --output` writes.
- `amc domain apply` no longer stores a composite score and level in `guardrails.yaml`; it records the assessment as not evaluated (`DomainApplyResult.assessment`), and its guardrail rules no longer follow gaps invented from the agent id: each pack contributes its first three questions.
- `scoreEUAIActCompliance` (10 criteria), `scoreISO42001Coverage` (8 controls) and `scoreOWASPLLMCoverage` (10 risks) counted file paths; `README.md` alone satisfied Art. 11. Each criterion is now not evaluated because file presence is not evidence, and the functions return `score: null` and `level: null`. The operator-declared EU risk class is kept and labelled self-reported. `scoreRegulatoryReadiness` returns `score: null` and lists the 28 criteria it could not evaluate. All four are deprecated. `scoreGamingResistance` reports `status: "not_evaluated"`, its source inventory lists present and missing paths with no 0-100 number, and the red-team CI gate still fails closed on it.
- The industry trust models no longer carry benchmark percentiles: the peer data and sample sizes were invented. `percentileRank` is `null` with reason "no peer data", `amc score industry-benchmark` reports not evaluated, and the observed-evidence share comes from the agent's latest sealed run instead of an assumed 80% (50% on the API), or is reported as not evaluated; an unsealed run file is not evidence.
- `CONSTRUCT_VALIDITY_DATA` keeps its record, but every study figure is `null`: no study was run.
- `amc mirofish run|compare|stress`, `amc demo run` (gateway and `--no-vault` modes) and `amc lab-simulate` print the synthetic-example banner, and their JSON carries `synthetic_example`; `amc demo run --json` reports trust label `DEMO_ONLY`, and `simulateExperiment` results carry the envelope in `metadata.envelope`. The gateway mode still records its scripted traffic for agent `default` in the workspace ledger.
- The dashboard Domains view no longer shows a score derived from a pack's risk tier when no assessment is returned; it shows not evaluated.

Removed or changed public API: `buildDomainAssessmentInput` and the `IndustryBenchmark` type are removed; `assessDomainForAgent`, `getDomainGaps`, `getDomainRoadmap`, `buildDomainReportForAgent` and `runDomainAssurance` return new shapes; the path scorers' booleans and counts are replaced by `criteria`, `controls` and `risks` lists; `GamingResistanceReport.controlInventory.score` and each control group's `score` are removed.
