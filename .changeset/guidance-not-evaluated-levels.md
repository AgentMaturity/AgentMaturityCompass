Upgrade and guide output no longer recommends the old gate requirements for a level AMC does not evaluate. Levels are cumulative, and under methodology r226 L3 to L5 (and L2 for questions without an evidence map) are not evaluated. Wherever output would need such a level, it names the lowest one, says "Not evaluated", gives the gate's reason (the evidence the question still needs, or the plan issue it waits on, such as P1-25, P1-26, P0-09 or P3-04) and promises no level gain. This covers `amc upgrade` plans (a task whose next level is not evaluated has no implementation, acceptance criteria or required evidence; a later one is noted under required evidence), the tuning pack's prompt addendum, `amc guide` and `amc fix` (sections give the reason in place of how-to-fix, evidence, agent instructions and commands for that level; commands still cover evaluable levels below it; the summary counts these gaps; guardrails list prohibited behaviors and evidence requirements only from gates AMC evaluates; `--json` gaps carry `notEvaluated`), `amc explain` example evidence, `amc delta-to-l5` items (new `notEvaluated` field, no L5 requirements listed), question-score repair hints, the diagnostic report's prioritized upgrade actions, why-capped next-level requirements, rapid quickscore recommendations, mechanic gaps (the reason is added, and an `OK` row becomes `BLOCKED`, as the Studio gap table shows), transformation task descriptions and org commitment plans. Advice for levels AMC can evaluate is unchanged and built from the rebuilt gates. The first-time guide no longer says most agents jump a full level by running `amc evidence collect`.
