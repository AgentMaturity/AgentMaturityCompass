The Compass Console explains AMC to a first-time user. The sign-in card now opens with one sentence on what AMC is and a plain username and password form; the "no account yet" instructions are numbered steps in a collapsed section, and the LAN-only pairing code and the emergency admin token sit under "Advanced". A signed-out visitor no longer sees the empty claim strip. Home opens a five-step "Welcome to AMC" guide on the first visit (what AMC is, how it works in three moves, a feature tour that links each page, the first step to pick, and a short glossary); closing it is remembered in the browser when storage is available, and the top bar's "How AMC works" link reopens it on any page. Home now leads with a welcome card and the existing start cards; each Activation path step says in plain words what it means and what to do next; the local command center, desktop app details and API quickstart are kept in full in collapsed sections labelled advanced or developer material; and the Unified Clarity labels have tooltips and a "What do these mean?" list. Every "All features" menu link carries a one-line description of its page.
