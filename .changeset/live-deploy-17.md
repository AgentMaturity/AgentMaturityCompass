One documented way to run AMC for live users, with Compose runbooks beside the reference runbooks (LIVE-DEPLOY-17). `docs/DEPLOYMENT.md` opens with "Running AMC for live users": the Compose TLS stack for a single host and the Helm chart 0.4.1 for a cluster, both documented and not qualified in D-03's vocabulary, the Compose HTTP stack for loopback or private networks, and Railway/Vercel for the standalone API only, with links to the reference runbooks. The new `docs/deploy/reference/COMPOSE.md` gives numbered steps for install, the monitor-key pin, pairing, backup (a signed bundle created inside the Studio container and streamed out, plus an archive of the state and checkpoint volumes), upgrade from the previous release and from 1.1.1 (including the one-time ownership change of the 1.1.1 HTTP stack's data volume), rollback with the restore, TLS for a public hostname, and A4 Forge's limits, and it lists what was run on 2026-11-08 and what was not. `docs/INSTALL.md` "Upgrading" starts with the backup and links the runbooks; the Compose README shows the `.env` image pin; the reference BACKUP_RESTORE runbook documents feeding the backup passphrase on stdin in Helm; the deployment checklist asks for Node.js 22 or 24.
