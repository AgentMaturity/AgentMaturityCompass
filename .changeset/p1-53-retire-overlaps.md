Domain rubric questions now load from the catalog; rubric certification readiness and cross-framework coverage are deprecated and no longer computed (P1-53). The 61 rubric questions live only in `catalog/questionnaires/domain-rubrics.yaml`, a self-reported questionnaire; `getDomainPackQuestions` returns the same questions in the same order, and `scoreDomainPack` (deprecated) reports `claimKind: "self_reported"`. `generateFrameworkReport` (deprecated) ignores passed questions and active modules: every control is `not_evaluated`, `coveragePercent` is 0 and `targetMet` is false. The new `listFrameworkCrosswalks(framework)` lists catalog crosswalks as information only. Compliance mappings gain `catalogControls` (default `[]`, so maps signed earlier still parse; built-in pairings are AI-proposed and pending review and change no result), `crosswalkRowsFromCatalog` feeds crosswalk receipts from the catalog, and `catalog/bindings/policy-packs.yaml` maps policy-pack settings to catalog binding parameters. The template-generated deep question exports are deprecated. No command or export is removed; P2-29 removes the deprecated ones. See docs/catalog/CONSOLIDATION.md.
