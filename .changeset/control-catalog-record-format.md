Adds the Regulated Control Catalog record format, loader and lockfile (experimental content; no regulated claims). The npm package now ships a `catalog/` folder with one example Layer 0 control, `L0-IDN-01` (unique agent identity bound to a human principal), its pack, vocabulary, evidence-producer registry and eight fixtures. `loadCatalog()` and `validateCatalog()` (`dist/catalog/index.js`) read it as data only and refuse YAML anchors, aliases, explicit tags, floats, unquoted dates, unknown keys and stray files; `buildCatalogLock()` and `verifyCatalogLock()` pin it with digests that formatting edits do not change. Citations are law as data: they carry the P0-25 citation-record fields, must use https on the shared official host list, are cross-checked against the regulatory register, and stay `unverified` until fetched and hashed. The example's HIPAA and GLBA citations are agent-drafted, unverified and have no register entry yet, so the control stays `experimental`; a control result is evidence of conformity, never proof of compliance. Three JSON Schemas are added under `spec/schemas/v1/`: `control-record`, `pack-manifest` and `catalog-lock`. No CLI command changes. See `docs/catalog/CONTROL_RECORD.md` and ADR 011.
