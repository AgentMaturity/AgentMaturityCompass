`amc --help` now has a "Studio and first run" block under "Start with a task": `amc up` (starts Studio and the Compass Console; the first run scores the workspace), `amc user init --username <you>` (the first console account, new workspace only; `amc user add` adds more), `amc down` and `amc domain pack list` (the free, self-reported Industry Packs). Before, the README's one command never appeared in the top-level help.
