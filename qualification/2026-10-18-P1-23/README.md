What this supports: for these cases, Claude Code 2.1.296 honoured AMC's PreToolUse answers, and AMC's forwarder answered allow only for a signed decision bound to the exact payload bytes, nonce, session and `tool_use_id` of a registered session. A registration is a lease-holder attestation; AMC cannot prove Claude Code ran a hook, and sessions without one are not governed. Decision and observation receipts are signed with the workspace's own receipt key: a local audit trail, not a portable verdict.

Reproduce: install Claude Code 2.1.296 into a scratch prefix with `npm install --ignore-scripts @anthropic-ai/claude-code@2.1.296 @anthropic-ai/claude-code-darwin-arm64@2.1.296`, `npm run build`, then `AMC_CLAUDE_CODE_CONFORMANCE=1 AMC_CLAUDE_CODE_PREFIX=<prefix> AMC_CLAUDE_CODE_CONFORMANCE_OUT=<file> npx vitest run tests/conformance/claudeCodeHooks.conformance.test.ts`.
