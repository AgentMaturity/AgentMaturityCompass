# Qualification: Claude Code 2.1.325 and pi 1.5.2 (2026-11-16)

Recorded on a local macOS arm64 machine (not CI) by the Watch lane, on branch `rtd/l-watch-1115`. The code under test is the parent commit named in `receipt.json` plus the two one-line additions committed with this record (`"2.1.325"` in `src/adapters/hookProviders/claudeCodePayloads.ts`, `"1.5.2"` in `src/adapters/pi/piVersions.ts`), built to `dist/` before each run.

- **Why:** Claude Code 2.1.325 (npm `latest`, published 2026-11-13) and pi 1.5.2 (npm `latest`, published 2026-11-10) were the current releases on 2026-11-16 (npm registry, read that day). Control mode refuses every call from an unqualified release, so an agent that updated itself lost control mode.
- **Claude Code 2.1.325:** installed from the public npm registry into a scratch prefix outside the repository (integrity and the native binary's SHA-256 are in `claude-code-conformance.json`). Its tool input types (`sdk-tools.d.ts`) are the same as 2.1.296's, so it uses 2.1.296's strict payload schemas. `tests/conformance/claudeCodeHooks.conformance.test.ts`: 7 of 7 passed with the same cases as the 2.1.296 run (allowed Read ran under AMC's verified allow; non-pure Bash, a Write needing approval, an MCP tool and a Write of `.claude/settings.json` were denied with no effect; a foreign PreToolUse hook left the session unregistered; a frozen workspace blocked the prompt; with the Bridge stopped the call was blocked; every decision and observation row verified cold). Latency sample n=30: p50 674.7 ms, p95 699 ms. The hooks reference was read again on 2026-11-16 (https://code.claude.com/docs/en/hooks); the pinned reference digest in `claudeCode.ts` was not changed, because existing installations sign it.
- **pi 1.5.2:** installed the same way. `tests/conformance/piToolCall.conformance.test.ts` for 1.5.2: 12 of 12 passed; events recorded to `tests/fixtures/harness-hooks/pi/1.5.2/events.jsonl`.
- The 2.1.296, 1.0.2 and 1.0.4 entries in the two records are copied unchanged from `qualification/2026-10-18-P1-23` and `qualification/2026-10-18-P1-22`.

What this supports: for these cases, these releases honoured AMC's answers at the listed hooks on this machine. It says nothing about other platforms, other releases, or sessions that ran no AMC hook.
