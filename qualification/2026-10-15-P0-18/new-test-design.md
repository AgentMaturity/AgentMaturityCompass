The proposed 14 registered cases cover one actual signed-list/ingest/cold-reader boundary: genuine pre-recorded pins and signatures; missing or foreign root; parseable signed-list tamper; own workspace signers; wrong purpose, revocation, expired entry, unpinned signer and forged attestation; genuine-signature subject/session/payload/original/time binding; duplicate and signed-time-window counting; actual writer refusal effects; and explicitly local legacy/synthetic projections. Existing importer, seven-format/time policy, dogfood diagnostic, source inventory, compliance and S7 coverage remains the baseline, not duplicated wholesale in this file.

Generate root and attester keys in an owned initializer child. Persist only public keys, independent canonical SPKI fingerprints and an ordered before-signature witness first. Actual signTrustList signs the domain tag AMC_TRUST_LIST_V1, one zero byte and recursively sorted canonical list JSON. Its signature is not a hex-digest signature. The attester signs 32 decoded digest bytes from bundleDigest, not the 64-character text. Independently verify both signatures with Node crypto. Actual loadTrustContext must read the signed list and separately captured root from the owned 0700 AMC_HOME; no constructed trusted context, artifact-derived pin, allow flag or validator mock is allowed.

Use actual ingestEvidence and attestIngestSession. Derive all original IDs, payload hashes, times, agent and session values from actual persisted rows. A positive cold assertion selects the bound attested review copy. The ATTESTED-stamped audit record lacks originalEventId and reads SELF_REPORTED under current binding; claiming all stamped rows are admissible would be wrong. attestedBy and statement are recorded labels outside the attester's signed bundle digest. Always call readerTrustFor(workspace), because the workspace argument supplies own-key exclusions.

All writes and fixture preparation finish in a child before any cold reader starts. The parent never opens a pooled ledger. Cold children use the existing openLedger(workspace, { readonly: true }); its real implementation has fileMustExist, no pool, no keys or migrations. SQLite may create WAL coordination sidecars. Keep pre-open and post-close inventories and raw rows, report sidecar effects separately, and define any narrower pure-helper no-rewrite interval explicitly. Compare evidence columns, signatures, database/payload/key/list bytes; do not erase unexplained effects. A fresh child and reader closure are essential when switching signed list variants, since readerTrustFor caches one load.

Private causal work starts only after root creates the lane, authorizes runtime and reports BUILDREADY. Copy the complete compiled closure and route every child import into it. Keep identical new-test inputs, public pins, argv and list variants for baseline, each mutant and restoration. A separate fixed actual seeder-export probe kills the opt-in mutation without adding fleet behavior to the permanent file. Restore and hash every copied input and rerun the identical corpus.
