# DeepSeek Harness — client/host/UI/interaction area report

## 1. PACKAGE PURPOSES

- `packages/client/web` — browser boot kernel (`AppWebEntry`): module stage → plugin stage → hand DOM to renderer; owns `PLATFORM_MODULES` static baseline.
- `packages/client/modules` — lazy-CJS browser module table; the Cordis Loader's `internal` seam ("how plugin code arrives"); Node half serves hashed bundles at `/plugins`.
- `packages/client/connection` — wire consumer: shared API client, `/api` HTTP bridge + two WS downlinks, browser-trust fence, loopback classification.
- `packages/client/runtime` — React-free object layer: SessionRuntime/WorkspaceRuntime, event windows, conversation-node assembler, projection value stores, queue mirror.
- `packages/client/ui-renderer` — all React machinery: slot outlets, hook binding from bare observables, hydrates the boot DOM.
- `packages/client/ui-slots` — pure slot core: one `register()` API, SlotMap declaration merging, four derived prop shares.
- `packages/client/hmr` — SSE-driven per-plugin hot reload; dependents cascade via Cordis service epochs.
- `packages/client/locale` — zh/en preference (Host-backed in `settings.yaml`), ns×locale dictionary registry, `t` standard seat.
- `packages/client/ui-*` (~30 feature plugins) — one feature = one plugin: layout, sidebar, theme, primitives, workspace, conversation (composer/chat/queue/stats), tool cards, trajectory view, workflow-run replay, goal, plan, jobs, subagent nav, model selection, permission presets, user questions, agent presets, settings (+general/models/plugins/plugin-inventory), commands, input-trigger, skill, reference (`@file`/`@session`), attachment UI, message feedback, deliverables (produced-files row), brand, directory-picker halves.
- `packages/host/apiproxy` — transport-independent API gateway (`ctx.apiProxy`): full RPC contract, zod-validated wire, projections push, session export.
- `packages/host/webserver` — bare `node:http` route/upgrade carrier with single fallback seat + index taps; `packages/host/frontend-static` — SPA dist server on that seat.
- `packages/host/directory-picker{,-native,-browse,-auto}` — capability seam (`native` OS chooser vs in-app `browse`), auto backend selection; `plugin-inventory` — read-only Loader entries projection.
- `packages/interaction` — `commands` (slash-command registry + lifecycle logging), `user-approval` (one-shot approval seam), `user-questions` (question/answer seam), `permission-presets` (sandbox+approval bundles), `tool-ask-user` (model-facing tool).
- `packages/feedback` — `command-feedback` (immutable log-only `feedback/record` + `/feedback`), `message-feedback` (editable per-message rating/note sidecar, never in model context).
- `packages/attachment` — durable image seam + content-addressed local store under `$DSH_HOME/attachments`.
- `packages/web` — provider-neutral search/fetch seam (`ctx.web`), providers (exa/perplexity/deepseek/http), model-facing `tool-web`.
- `packages/runtime-diagnostics/invariants` — `ctx.invariants` registry; every workspace package ships a `./invariant` companion.
- `apps/cli` — `dsh` launcher: profile boot, plugin management, web alias; `apps/web` — Vite entry over the client-web shell; ~90 real-Chromium e2e specs.

## 2. KEY MECHANISMS

**Host/client split**: every package builds two faces (`tsconfig.host.json` / `tsconfig.client.json`; tsdown `DSH_BUILD_FACE`). Host = Cordis plugins on Node providing services; client = `./client` export loaded as a script bundle into the browser's module table. `dsh web` boots the host tree (`packages/bundle/web-app/cordis.patch.yml`), which serves `apps/web/dist` and per-plugin `lib/client.js` bundles; the browser mounts its own Cordis Loader mirroring the graph (`packages/client/web/src/platform.ts`, `packages/client/modules`).

**RPC**: four-quadrant wire (`ClientRequest`/`ServerResponse`/`ServerRequest`/`ClientResponse`) in `packages/host/apiproxy/src/api/`; unary = POST `/api/<method>`, host-initiated = two downlink-only WebSockets (`events.mux`, `events.host`); interactive answers = POST `/api/respond`. rpcId minted by initiator, echoed by responder; envelope zod-parsed then per-method payload parsed. `AbstractApiClient` (`src/fetch/`) holds every protocol invariant; platform subclasses supply only `doFetch`; `InProcessApiClient` gives full wire validation with no network. Security: 415 on non-JSON media type (CSRF), Host-header trust fence with WHATWG-normalized `trustedHosts` (DNS-rebinding defense, `packages/client/connection/src/api-request-trust.ts`), privileged methods (settings/credentials/preset-authoring/native actions) pinned to loopback.

**Interaction model**: model tools block on services — `ask_user_question` → `ctx.userQuestions.ask()` (one provider, Web host runtime supplies it); tool pipeline `ask` decisions → `ctx.approval.request()` (waterfall answerers, fail-closed, paired log-only `approval/asked`/`decided` audit; model sees only tool outcome). Pending waits ride mux frames; the browser composer is *taken over* (question card or `ApprovalPanel` replaces the InputBar via the keyed `conversation.composer` slot); answers POST `/api/respond`; `SessionSummary.pendingInteraction` classifies waiting sessions (`approval`/`plan-review`/`question`) even before instantiation. Slash commands run host-side (`command.execute`), logged as `command/run`/`command/done`, never entering model history. Steering vs queueing: `session.prompt(mode)` with Enter-behavior preference; queue derived from durable `agent/inbox/spliced`.

**Client architecture**: three layers with one-way knowledge — React-free object layer (runtime), render machinery (ui-renderer), pure-props components. Notifier tiering in `packages/client/runtime/src/client/sessions/notifier.ts`: `notifyNow` (gesture echo) / `markDirty` (microtask batch) / `markFrameDirty` (streaming, once per animation frame).

**Diagnostics**: `ctx.invariants.register(pkg, installer)` runs checks in child fibers, regex allow/blocklists; companions verify session enclosure, agent-status transitions, inbox FIFO, prompt reconstruction, approval audit pairing.

## 4. PATTERNS WORTH STEALING

- **Slot registration = declaration + authorization**: one `register({name, children, store, inject}, Component)` where the `children` keys are the only slots you may render; props are four *derived* shares; components never see ctx (`packages/client/ui-slots`, `packages/client/AGENTS.md`).
- **Host-header trust fence** covering unmarked requests too (rebinding can't forge Host), plus loopback-pinning of the privileged method set instead of auth theater (`packages/client/connection/src/api-request-trust.ts`).
- **Generic projection channel**: host-computed per-session key/value units with `asOfSeq`, baseline-on-history-tail + higher-seq-wins push — new derived UI facts need no new wire surface (`packages/host/apiproxy/src/api-proxy.ts`).
- **Presentation intent on questions** (`plan-review`): a tag changes layout, never the answer space, so unaware UIs degrade to the generic form (`packages/interaction/user-questions`).
- **Approval audit log-only; model sees only the tool outcome** — zero duplicate tokens, KV-cache-append-only policy switches (`packages/interaction/user-approval`).
- **"Model Experience" + "KV Cache effect" section required in every package README**, verified by `scripts/verify-package-readme-model-experience.ts` — token/cache cost as a first-class review axis.
- **Per-package `./invariant` companions** with an explicit "No runtime invariant:" escape hatch (`packages/runtime-diagnostics/invariants`).
- **Startup RPC budget pinned by test** (`apps/web/tests/startup-rpc-budget.e2e.ts`) — cold-boot chattiness is a regression.
- **Notifier tiering** (gesture/microtask/frame) for streaming UIs (`packages/client/runtime/src/client/sessions/notifier.ts`).
- **Capability-union seams** (`directory-picker.capability().kind`) where backends differ in *user interaction*, and one composition row installs both host backend and client flow.
- **HMR cascade via DI epochs**: replacing a provider fiber restrings dependents with zero client graph analysis (`packages/client/hmr`).
- **`recordInput: false`** so a command's authoritative domain event isn't double-logged (`packages/interaction/commands`).
- **Copy-only preset authoring**: no composition text or path ever crosses the wire (`agentPreset.copy`).
