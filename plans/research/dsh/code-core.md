# Cordis-Foundation Packages Report (core, boot, context, typert, util)

Note: `packages/composition.md` does not exist; composition/HMR docs live at `docs/cordis-tutorial/06-composition-and-hmr.md` and per-app `apps/cli/composition.md`. The Cordis framework itself is vendored at `vendor/cordis` (plus `vendor/loader`, `vendor/hmr`, `vendor/schemastery`, etc.) as `@deepseek-ai/cordis`.

## 1. PACKAGE PURPOSES
- `packages/core/scope` — scoped-context registration primitive: opaque scope keys, parent chains, scope-filtered event dispatch (library, no ctx key).
- `packages/core/session` — event-sourced append-only session log + in-memory store (`ctx.sessions`); LLM history is *derived* from it via a "surface" projection.
- `packages/core/system-prompt` — prompt/tool-schema assembly registry (`ctx.systemPrompt`): ordered sections, variables, dynamic contexts, tool providers.
- `packages/core/tools` — scoped tool registry + execution pipeline (`ctx.tools`), native/Code-Mode presentation, schema DSL.
- `packages/core/agent` — abstract `Agent` interface, registry, initiator scope, `agent/*` event vocabulary (`ctx.agents`); zero loop dependency.
- `packages/core/agent-loop` — THE concrete driver (`ctx.agentLoop`), the only package with loop logic; implements `AgentFactory`.
- `packages/core/agent-default-model` — deployment default `{provider, model}` selection service (`ctx.agentDefaultModel`), settings-layered.
- `packages/core/agent-tool-presentation` — preset row selecting per-agent tool presentation (native/code/both).
- `packages/boot/app-boot` — shared bin boot glue: `.env` layers, fail-loud guards, Loader mount, profiles/bundles, user patch HMR.
- `packages/boot/cmdline` — launcher→app argv handoff (`ctx.cmdlineArgs`, `ctx.appExit`); apps own their flags.
- `packages/context/*` — model-visible request context plugins: `agent-instructions` (AGENTS.md/CLAUDE.md loading), `time-context`, `tmux-context`, `session-reference` (@session snapshots), `file-reference` (+`-local`) (@file grammar/provider).
- `packages/typert/*` — runtime type system: `generator` (TS→compiler-independent FaceModel/TypeGraph + Zod emission), `registry` (`ctx.typert` runtime reflection/schema store), `loader` (auto-discovers `./typert` artifacts from Loader entries), `protocol` (`@Remote` decorators, RPC descriptors, codecs).
- `packages/util/*` — zero-dep primitives: `brand` (nominal types), `home-paths` (`$DSH_HOME`/`~/.dsh`), `timeout` (deadline/classification), `output-retention` (bounded output), `atomic-write`, `native-command`, `launch-environment` (source-tracked env layers).

## 2. KEY MECHANISMS
**Plugin/effect model (vendored Cordis; `docs/cordis-tutorial/02`)**: every capability is a plugin (function, object, or `Service` subclass). `ctx.plugin()` returns a **fiber** with state machine PENDING→LOADING→ACTIVE→UNLOADING→DISPOSED (or FAILED). All registrations (`ctx.on`, `ctx.plugin`, service registration, harness registries) are **effects** undone on unload; unmanaged resources wrap in `ctx.effect(() => disposer)`. Disposers run reverse-order; async disposers run concurrently.

**Service injection (coeffects)**: `Service` subclass registers under a name; consumers declare `inject: ['name']` and stay PENDING until providers exist. Dependencies are tracked *after* load: a provider unloading unloads all dependents, which reload when it returns — this is what makes provider swapping and HMR safe. Optional deps use `ctx.get(name)` (strict global store; the property proxy is topology-sensitive — `packages/AGENTS.md`).

**Loader/config reconciliation/HMR (`docs/cordis-tutorial/06`)**: `cordis.yml` entries carry `id` (stable identity), `disabled`, groups, `isolate` (per-group service realms), `!!js` lazy expressions evaluated after the row's injections activate (`packages/boot/cmdline/README.md`). The loader diffs entries by id and mounts/unmounts/reconfigures only what changed; `cordis-plugin-hmr` watches files and unload+reloads plugins on save.

**Scopes (`packages/core/scope/src/index.ts`)**: `createScope(ctx, key)` mints a tagged context whose backing fiber owns all registrations. Parent chains (`bindScopeParent`, cycle-checked, rebind only via the returned capability): registration views inherit DOWN (child sees ancestor layers, nearest shadows), events flow UP (ancestor-tagged listeners receive descendant events, never reverse). `scopeTarget(base, key)` builds an opaque `Scoped<T>` dispatch carrier composing Cordis `Context.filter`. `ScopedLayers` gives registries one eager global layer + lazy per-scope layers with merge/shadow semantics. The loop mints one scope per agent (`agent.ctx`); presets are parent scopes.

**Tool pipeline (`packages/core/tools/README.md`)**: `tools/pre-execute` (allow/deny/ask waterfall) → monotonic `guard()`s → `tools/execute` (around wrapper; may replace only `signal`) → body → `tools/post-execute` (replace content XOR value, block, attach contexts) → definition-owned `finalizeContent` → observe-only `tools/result`. Arguments frozen/snapshotted; opaque `ToolExecutionToken` correlates nested calls; cooperative cancellation with typed causes (`ABORTED_BEFORE_DISPATCH` etc.). Code Mode: reserved `run_code` transport + deterministic per-scope generated SDK (TS/Python), sub-calls re-enter the full pipeline with `parent` token, logged as `tool/code-dispatch*` events.

**Session log (`packages/core/session/README.md`)**: append-only events with `sourceEventSeqs` (citations), `surfaceOp` (surface membership incl. `replace` for compaction), `ignorable` (forward-compat skip marker). `deriveMessages()` projects the surface incrementally; `request/header` snapshots the full non-history envelope so requests are reconstructable; crash repair synthesizes `TOOL_NOT_STARTED`/`TOOL_OUTCOME_UNKNOWN` results with risk-specific retry guidance.

**Boot (`packages/boot/app-boot/src/index.ts`)**: `boot()` = root context → `dshHomePath` exposed to `!!js` → Loader install → optional `prepare` → mount include tree → `assertEntriesLoaded`/`assertEntriesActivated` (PENDING entries fail loud naming unresolved services) → return ctx or dispose partial tree. Profiles under `$DSH_HOME/profiles/<name>` layer bundle `cordis.patch.yml` files + user patches, live-watched (`watchUserPatches`); failed reload keeps last good tree.

**Typert**: build-time analyzer converts TS types into a compiler-independent model, emits Zod schemas + `TYPERT` contributions at `lib/typert.host.js`; `dsh-typert-loader` auto-imports `./typert` exports of mounted Loader entries into `ctx.typert`; `@Remote`/`@RemoteScope` decorators (WeakMap-held markers, no prototype pollution) mark methods for RPC with trailing-`AbortSignal` cancellation.

## 4. PATTERNS WORTH STEALING
- **Everything-is-a-disposable-effect + PENDING-until-service-ready** (`docs/cordis-tutorial/02-03`): registrations auto-unwind and dependents restart on provider swap — HMR and config reconciliation fall out for free. Registry contributions must *prove* disposal via a mandated HMR-safety test (`packages/AGENTS.md`).
- **Scope carriers** (`packages/core/scope/src/index.ts`): compile-time-branded `Scoped<T>` dispatch targets make unscoped dispatch a type error; events up / visibility down along a parent chain is a clean multi-agent isolation model without sandboxing claims.
- **Event-sourced session with citation metadata** (`packages/core/session`): `sourceEventSeqs` + `surfaceOp` + `ignorable` give replaceable derived history, exact request reconstruction (`request/header`), and forward-compatible logs; crash repair emits risk-aware synthetic tool results.
- **Canonical value vs. presentation split** in tools: typed JSON value (execution-local) vs. rendered content (durable), with `finalizeContent` as the single last content boundary and UI render-intent cards so UIs never special-case tool names.
- **Code Mode executor collapse**: under `code`, non-`run_code` direct calls fail *at execution creation* with a route-back message — announced surface == callable surface.
- **KV-cache/token "Model Experience" sections in every README** — each package documents what the model sees, token cost, and prefix-stability impact. Rare and extremely useful discipline.
- **`!!js` config lazily evaluated after injection** (`packages/boot/cmdline`): CLI flags flow into config rows through ordinary service injection, surviving reloads.
- **Fail-loud boot audit** (`app-boot`): settled-tree assertions name every PENDING plugin's unresolved services; partial-tree disposal restores the terminal before exit.
- **Source-tracked env layers with omission-as-refusal** (`util/launch-environment`); **timeout = notification + classification only, termination stays local** (`util/timeout`); **`truncated` is a budget fact, never "incomplete"** (`util/output-retention`).
- **`./invariant` companion per package** wired to a runtime invariant checker (`verify-package-invariants`).
