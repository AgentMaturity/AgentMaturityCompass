# Tool-Execution Packages — DeepSeek Harness

## 1. PACKAGE PURPOSES
- `packages/shell/shell` — abstract `ctx.shell` executor seam (`resolve`/`run`/`start`), shared exit-status vocabulary; `shell-env` — `ctx.shellEnv` registry of trusted per-execution `DSH_*` vars.
- `packages/shell/bash-local` / `bash-sandbox` — local bash executor over `ctx.subprocess`; sandbox variant wraps the exact `['bash','-c',cmd]` argv through `ctx.sandbox`.
- `packages/shell/pwsh-local` / `pwsh-sandbox` — PowerShell twins (spawn `pwsh -NoLogo -NoProfile -NonInteractive -Command`), call-for-call mirrors of the bash pair.
- `packages/shell/tool-bash` / `tool-pwsh` — model-facing one-shot shell tools + background-job adaptation; `tool-bash-persistent` / `tool-pwsh-persistent` — alternate `bash(command)` tool backed by one owner-scoped PTY shell.
- `packages/subprocess/subprocess` / `subprocess-local` — the process substrate: fully-explicit spawn specs, offset-based collected output with spill files, tree-scoped termination, `node-pty` terminal primitive, credential scrub.
- `packages/terminal/terminal` / `terminal-bash` / `tool-terminal` — persistent PTY sessions: branded ids + exact-Agent ownership registry; bash/pwsh readiness-detecting backend; six model-facing `terminal_*` tools.
- `packages/fs/fs` / `fs-local` / `fs-sandbox` / `fs-observation-policy` / `tool-fs` / `tool-fs-search` / `tool-str-replace-editor` — filesystem seam (opaque targets, version guards, atomic mutation), local disk impl, in-process write fence, read-before-edit policy plugin, model `read`/`read_image`/`write`/`edit` tools, ripgrep-backed `glob`/`grep`, and an Anthropic-style `str_replace_editor`.
- `packages/sandbox/sandbox` / `sandbox-local` / `sandbox-policy` / `sandbox-windows-acl` — `ctx.sandbox.confine(argv, policy)` seam; bwrap/Landlock/Seatbelt runner selection; per-session durable mode resolution; Windows `WRITE_RESTRICTED`-token backend.
- `packages/code-runtime/*` — "Code Mode" seam: run one model-written program against host bindings; worker-thread TypeScript backend; Python subprocess wire protocol.
- `packages/e2b/*` — experimental POC: E2B cloud Linux sandbox as a replacement execution world (`ctx.e2b` lifecycle + `fs-e2b` + `subprocess-e2b`); bash/PTY/LSP consumers work unmodified.
- `packages/lsp/*` — LSP seam (four ops, no JSON-RPC escape hatch), generic stdio host, model `lsp` tool.
- `native/landlock-run` — ~300-line C11 musl-static self-restrict-then-exec Landlock launcher, shipped as npm entry + per-arch optional packages.

## 2. KEY MECHANISMS
- **Seam architecture**: every capability splits Service Definition (abstract class on `ctx.*`), Service Provider (swappable plugin), Consumer (model-facing tool). `packages/shell/shell/src/types.ts`, `packages/subprocess/subprocess/src/index.ts`. Docs in `docs/subsystems/*.md` embed generated, drift-checked API catalogs (`scripts/gen-cordis-catalog.ts`).
- **Request→spec resolve() split**: tools pass optional-field requests; `ctx.shell.resolve()` fills defaults/caps so executors only see fully-resolved `ShellExecSpec` ("explicit > implicit at package boundaries").
- **Subprocess substrate** (`packages/subprocess/subprocess-local/src/spawn.ts`): detached process groups, SIGTERM→grace→SIGKILL `terminate()` (Windows `taskkill /T /F`), `waitForExit()` polling whole-tree liveness, per-stream dispositions (`pipe`/`inherit`/collect{maxBytes, spill}), tail-keeping bounded collectors with full-stream 0600 spill files, offset-based non-consuming readers, credential scrub (`*KEY*/*PASSWORD*/*SECRET*/*TOKEN*` + ambient `DSH_*` removal), and a synchronous Node `exit` listener that force-kills every live tree.
- **Sandboxing** (`packages/sandbox/sandbox-local/src/profiles.ts`): per-call `SandboxExecutionPolicy` {mode, workspaceRoot, sessionId} resolved by `ctx.sandboxPolicy`; `confine()` returns wrapped argv + `enforcement: full|partial` + per-backend `denialSignatures` (EROFS/bwrap, EACCES/Landlock, EPERM/Seatbelt) + structured `runnerFailureRules`. Linux prefers bwrap then Landlock (functional probes, cached); macOS Seatbelt via allow-default `(deny file-write*)` SBPL; Windows ACL restricted token (deterministic per-workspace SID, random per-session temp SID). Fail-closed `SANDBOX_UNAVAILABLE`; never silent passthrough. `landlock-run` exits 125 with `landlock-run:` stderr prefix so consumers can attribute launcher failure vs child exit (`native/landlock-run/docs/cli-contract.md`).
- **fs freshness policy** (`packages/fs/fs/src/index.ts`): tool dispatches `fs/write-intent` / `fs/edit-intent` waterfall events; the policy plugin maps per-session observed state (WeakMap keyed on session) to `createIfAbsent` / `replaceIfVersion` guards; provider enforces atomically (temp file + fsync + rename; `createIfAbsent` publishes via hard-link for atomic no-replace; Windows `ReplaceFileW` DACL preservation).
- **PTY readiness** (`packages/terminal/terminal-bash/src/session.ts`): layered evidence — OSC `133;D`-marked controlled `PS1` prompt verified against foreground group, provider-proven foreground stdin-wait, bounded silence, absolute timeout; evidence predating the write is discarded; `handoffGraceMs` covers marker/foreground races.
- **Code Mode** (`packages/code-runtime/code-runtime-worker-thread/src/worker.ts`): one fresh worker per run, host-side type-strip, bindings bridged over the message port with the worker treated as a hostile peer (rebuilt messages, null-prototype namespaces, captured intrinsics), dual budgets (measured event-loop busy time + wall clock), empty env, byte-accounted output ledger.
- **LSP** (`packages/lsp/lsp-stdio/src/host.ts`): lazy single-flight server per (id, workspace), transient didOpen→query→didClose per query, per-workspace abortable queue, one fresh-process retry, tree-kill teardown via the subprocess seam.

## 3. FEATURE INVENTORY
- `bash` tool: `command`, `description`, `timeoutMs`, `workdir` (defaults to session cwd), `run_in_background` (returns `started background job <id>`, controlled via `job_output`/`job_list`/`job_kill`), conditional `sandbox_permissions` (`workspace-write`|`danger-full-access`) + `justification` (advertised only when executor sandboxes; one-shot approval via `ctx.approval`, strict-widening check).
- Result markers: `[exit code: N]`, `[killed by signal: X]`, `[timed out after Nms]`, `[stderr]`, `[output truncated; full output: <spill path>]`, `[sandbox: file access denied under <mode> mode]`; nonzero exit is a model result, never `isError`; orthogonal `timedOut`/`aborted`/`signal`/`exitCode` fields.
- Trusted-plugin-only request fields: `stdin`, `env`, `stdoutMaxBytes` (not model-exposed).
- Managed env: `DSH_HOME`, `DSH_SHELL=1`, `DSH_SESSION_ID`, `DSH_SESSION_JSONL`; plugin-registerable contributors with declared keys, loud duplicate failure, `list()` enumeration.
- Sandbox modes: `read-only` (writes only `/dev/null`), `workspace-write` (workspace root + `/tmp` + `os.tmpdir()`), `danger-full-access`; per-session durable override (`sandbox/mode` event) > deployment default; `sandbox-local` config: `runnerCommand` custom runner + `runnerFailureSignatures`, `probeTimeoutMs`.
- `landlock-run` CLI: `--ro <path>`/`--rw <path>`/`--`/`--probe`; exit 125 contract; probe reports full/partial/unusable; JS API `launcherPath()`, `probe()`, `grantArgs()`.
- fs tools: `read` (`offset`/`limit`, 2000-line/51200-byte caps, line numbering, streaming ≥10MiB), `read_image` (PNG/JPEG/WebP/GIF, registers only with attachment store + image-capable model), `write`, `edit` (`old_string`/`new_string`/`replace_all`); no timeouts on file IO by design; error taxonomy of 13 `FS_*` codes; `str_replace_editor` (`view`/`create`/`str_replace`/`insert`).
- Search tools: `glob` (`pattern`,`path`; rg `--files --sort=modified`, VCS excludes) and `grep` (`pattern`,`path`,`include`; `rg --json` parse); config `sampleOverCapGlobResults` (required), `globMaxResults` 100, `grepMaxMatches` 250, `grepMaxLineBytes`, `rawOutputMaxBytes` 20MB, `timeoutMs`/`graceMs`/`stderrMaxBytes`; `--no-config` blocks `RIPGREP_CONFIG_PATH` `--pre` injection; over-cap results spill to `ctx.spillStore` with retrieval locator.
- Terminal tools: `terminal_open` (`type`,`name`,`cwd`), `terminal_send` (`text`,`submit`,`run_in_background`), `terminal_read` (newest-relative `offset`,`count`), `terminal_signal` (SIGINT/SIGTERM/SIGKILL/SIGTSTP/SIGHUP; shell-targeted SIGKILL rejected), `terminal_close`, `terminal_list`; exact-Agent ownership; wait reasons `stdin_read|inferred_idle|timeout|session_exit`; config `enableRunInBackground`, `maxResultBytes` 256KiB; bash + pwsh dialects; mode-change fenced while PTYs open.
- Persistent bash tool: `backendType`, `timeoutMs` 300s (timeout closes+resets shell), `maxOutputChars` 16000, custom `description`; shell state (cwd, exports, venvs) persists per Agent.
- Code runtime: `run_code` tool via `tools: {mode: code}`; worker config `computeMs` 60s, `maxWallMs` 600s, `maxOutputBytes` 64MiB, `maxOldGenerationSizeMb` 512; failure kinds `exception|timeout|abort|worker-exit|invalid-output|output-limit`; languages `typescript` (shipped) / `python` (fd-3 JSON-lines protocol, lossless BigInt integer crossing).
- LSP: `lsp` tool (`operation`, `file_path`, one-based `line`/`character`); per-server config `command`/`args`/`env`/`extensionToLanguage`/`initializationOptions`/`configuration`/`maxMessageBytes`/`maxStderrBytes`/`maxDocumentBytes`/`shutdownTimeoutMs`/`killGraceMs`; tool config `maxLocations` 100, `maxResultChars`, `timeoutMs`; rejects `workspace/applyEdit` (read-only).
- E2B: `apiKey`/`E2B_API_KEY`, `cwd` (default `/home/user/workspace`), `timeoutMs` sandbox lifetime, `pollMs`; setsid process groups, base64 stdio framing, remote spill under `.dsh-e2b`.

## 4. PATTERNS WORTH STEALING
- **Per-call sandbox policy, deny-report-escalate loop**: policy resolved fresh per tool call (session mode + immutable cwd), denials are result facts matched against the selected backend's own stderr dialect, and the model retries once with `sandbox_permissions`+`justification` gated by human approval (`packages/shell/bash-sandbox/README.md`, `docs/subsystems/sandbox.md`).
- **Runner-failure vs denial vs command-failure attribution** via structured `RunnerFailureRule` (exit-code gate + fatal signature after informational-line exclusion) — never blame the command for broken infrastructure (`packages/sandbox/sandbox/src/index.ts`).
- **Read-before-edit as a droppable event-gate plugin**, version-guarded (`replaceIfVersion`) rather than mtime-based, with observed-absence authorizing recreate-not-edit (`packages/fs/fs-observation-policy`).
- **Offset-based, non-consuming output readers + tail-keep with full-stream spill files** — multiple readers coexist; truncated results always link recovery (`packages/subprocess/subprocess-local/README.md`).
- **Orthogonal outcome fields** (`timedOut` AND `exitCode` both reported; first-cause abort/timeout mutual exclusion) so a trapped signal can't masquerade as success (`docs/subsystems/shell.md`).
- **DSH_* managed-env channel**: scrub-ambient-then-merge-snapshot prevents nested-harness identity leakage (`packages/shell/shell-env`).
- **PTY readiness evidence ladder** with foreground-group verification and write-boundary evidence discard (`packages/terminal/terminal-bash`).
- **Hostile-peer code runtime** (rebuilt port messages, captured intrinsics, dual busy/wall budgets) (`packages/code-runtime/code-runtime-worker-thread/README.md`).
- **Portable execution world**: fs + subprocess seams are the only OS adapters, so swapping in E2B relocates bash/PTY/LSP wholesale with zero forks (`packages/e2b/README.md`).
- **Every README documents Model Experience**: token cost and KV-cache invalidation of each prompt section, schema, and result — cache-stability as a first-class design axis.
- **Fail-closed native launcher** with reserved exit 125 + prefixed fatal line, shipped as entry + per-arch optional npm packages with no build fallback (`native/landlock-run`).

## 5. MATURITY NOTES
- Every one of the 35 packages has tests (1–14 spec files each; heaviest: sandbox-windows-acl 14, lsp-stdio 10, subprocess-local 8, tool-fs 8); Python runtime has a cross-language protocol-mirror e2e spawning real `python3`; doc catalogs are CI-verified (`verify-cordis-catalog`).
- ~15 tracked inline TODOs, all narrow and annotated (e.g. `pty-send-state-consolidation`, `e2b-pgid-identity`, `background-infrastructure-outcome`); design debts recorded in `.agents/notes/implemented/` decision notes.
- Every README carries an honest "Known Limitations and Deferred Work" section: Windows ACL and old-Landlock-ABI enforcement reported `partial`; Seatbelt rides deprecated `sandbox-exec`; worker-thread runtime can't kill OS processes a program spawns; spill files accumulate in tmpdir; credential scrub is a name heuristic; PTY sessions don't survive process exit.
- Explicitly experimental: the whole `packages/e2b/` family (POC; SDK buffers full output host-side, `pid: -1` during startup, no host sync) and `packages/experimental/` (agent-team, outside this area). Code Mode Python backend ships protocol only — no published execution path. Feature flags are composition-level (which plugins a `cordis.yml` loads) rather than runtime flags.
