# DeepSeek Harness — Session & State Packages

## 1. PACKAGE PURPOSES

- `packages/session/session-persistence` — abstract durability seam `ctx.sessionPersistence` (locate/create/append/prepare/load/inspect/readFrom/list/listSnapshots) + shared write coordinator.
- `packages/session/session-persistence-jsonl` — per-session append-only JSONL logs, zstd-framed by default, crash-safe atomic writes.
- `packages/session/session-persistence-sqlite` — opt-in single-DB backend (schema 17), packed chunk rows, selective zstd, varint provenance.
- `packages/session/session-checkpoint-policy` — semantic flush checkpoints: before model dispatch, before tool side effects, at `agent/pre-step`.
- `packages/session/session-projection` + `session-projection-cache` — registry of pure fold units over the event log, served to UIs; persisted `(key, ver, seq, val)` checkpoints as fold shortcuts.
- `packages/session/session-stats` — projection unit: turn/step counts, LLM/tool/TTFT/decode wall times.
- `packages/session/session-title{,-llm,-first-prompt-llm,-all-prompts-llm}` — log-backed titles: deterministic fallback + one optional LLM provider.
- `packages/session/session-telemetry{,-otel}` — capture/redact/project session records to a reporting backend; OTel logs delivery in FULL/FEEDBACK_ONLY/DISABLED modes.
- `packages/session-query/*` — authorized retrieval over live+durable logs: filters, traces, SQLite FTS5 search, model tools, Web `/export` ZIP.
- `packages/compaction/*` — compaction seam, summarizing backend, model-free tool-result pruner, `/compact` command.
- `packages/spill/*` — **spill = persisting oversized tool output to session-scoped files**, replacing inline results with a head/tail preview + opaque locator + retrieval hint.
- `packages/storage/*` — non-session storage: named backends (json/sqlite) behind a hub, typed zod-validated "domain" KV form.
- `packages/workspace/workspace` — durable workspace entities: realpath-canonical directory + title + ordered session membership.
- `packages/settings/*` — namespaced user settings: schema defaults → composition `base` → user layer; file provider with watcher + writer lock.
- `packages/todo/tool-todo` — model-facing `todo_write` whole-list-replace tool.
- `packages/plan/plan-mode` — logged plan-mode collaboration state, `plan:policy` prompt section, `exit_plan_mode` tool, `/plan` command.
- `packages/goal/*` — durable same-session goal state, model tools, `/goal` command, autonomous goal-round continuation driver.

## 2. KEY MECHANISMS

**Event-sourced session core.** The `Session` is an append-only log of typed `SessionEvent`s; LLM history is *derived*, never stored (`docs/subsystems/session.md`). Surface events (`user/message`, `assistant/message`, `tool/result`) carry `surfaceOp` (`append` or `{replace, start, end}`) and `sourceEventSeqs` provenance. `SessionEventMap` is merge-extensible via declaration merging (compaction adds `compaction/*`, plan adds `plan/mode`, goal adds `goal/change`). Unknown event types without `ignorable: true` refuse reconstruction rather than silently drop.

**Persistence** (`docs/subsystems/persistence.md`, `packages/session/session-persistence/src/{coordinator,write-behind}.ts`). `session/event` copies into a per-session controller; a fixed batching window (default 200ms, non-resetting) coalesces batches; `session/flush` drains through quiescence. Crash recovery closes an orphaned turn with synthetic `turn/end {reason: interrupted}` — never truncates a huge interrupted turn. `prepare(id)` returns a disposable unpublished Session (LRU-cached so inspect→resume shares one decode). `listSnapshots()` returns cheap opaque revisions (JSONL: device/inode/size/ns-mtime). `SessionHeader` (version, cwd, lineage `parentSession`+`seedLength`, `origin: 'subagent'`, `delegationDepth`, `agentPreset`) travels beside the log, never in it. Format refusal (`SessionFormatUnsupportedError`) is distinct from corruption and names the upgrade direction.

**Compaction** (`packages/compaction/compaction-basic`). Pressure runs at `agent/pre-step` when tokens exceed `thresholdRatio` (0.8) of the context window; retains a `retainRatio` (0.16) tail. The whole operation is bracketed by log-recorded lock events `compaction/start`/`end`; the summary rides a `user/message` with `surfaceOp: replace` so the log stays append-only while the surface shrinks. Before summarizing, the optional `ctx.toolResultPruner` deterministically drops tool-result middles (>8192 chars → 4096 head + 1024 tail), remeasures, and may avoid summarization entirely. `compaction/summary` logs provider/model/maxTokens/rawOutput so the one-shot request is reconstructable from log + code.

**Spill** (`packages/spill/spill-local/src/store.ts`, `spill-policy`). A `tools/post-execute` policy: any plain-text final result over `maxInlineBytes` is saved verbatim to `<root>/session-<sha256(id)>/<random>-<safeName>` (0700 dir, `open 'wx' 0600` symlink-proof), and the inline result becomes preview + branded `SpillLocator` + `retrievalHint` ("use read/grep on this path"). Save failure keeps the original inline — best-effort, never turns success into error.

**Storage domain** (`docs/subsystems/storage.md`). Hub `ctx.storage` registers named backends; consumers use `defineDomain(spec)` (zod tables + optional global singleton, version-stamped) and get sync in-memory reads with a serialized write chain: durable-first, then memory, then `domain/changed` emit.

**Settings** (`packages/settings/settings-file`). Per-write read-modify-write under a `wx` `.lock` sibling (2s deadline); YAML leaf-diff writes preserve comments and unloaded plugins' sections; watcher hot-publishes external edits with last-good fallback; `role('secret')` redaction plus path-op mutation (`SettingsPathOp`) so a redacted UI can't delete secrets it never saw; optimistic `expectedRevision` concurrency.

**Projections** (`packages/session/session-projection`). Domains register `{key, schema, init, apply, view, stateVersion}` pure sync units; the framework subscribes to `session/event` once, gates change-feed on `Object.is`, and `snapshot()` gives one consistent cut (`asOfSeq`). Cache rows are validated against header identity and discarded (never migrated) on `stateVersion` bump; the log flushes before the cache row lands, so cache is stale-but-never-wrong.

**Goal continuation** (`packages/goal/goal-round-driver`). At agent idle, an active+armed goal with round capacity reserves round N+1, flushes, and queues one `<goal_round>` prompt with `GoalMessageSource {goalId, revision, round}`; human input always yields; activation is process-local and never inherited across resume/fork — humans must explicitly `resume`.

## 3. FEATURE INVENTORY

**Commands:** `/compact` (manual idle compaction; stable errors for busy/changed/summary/commit/persistence); `/plan [message|off]` (enter + optionally steer message under guidance; `off` exits and cancels pending entry; image attachments ride steered message); `/goal`, `/goal <objective>`, `/goal edit|pause|resume|clear` (case-insensitive control words only when whole input); `/export` (Web-only ZIP download via HEAD preflight + browser download manager, includes descendants).

**Model tools:** `todo_write(todos)` (whole-list replace; rejects empty/duplicate content, extra keys); `exit_plan_mode` (always registered for schema stability; requires `#`-headed markdown plan; approval via user-questions review with `plan-review` intent; keep-planning = failed call with feedback); `get_goal`/`create_goal`/`update_goal` (compare-and-set id+revision; `blocked` requires `blockedAfterConsecutiveRounds`, default guidance 3; `complete`/`blocked` from a goal round call `concludeTurn()`); `session_search`, `session_event_search`, `session_trace`, `session_event_trace`, `session_event_read` (workspace-authorized via exact cwd equality; caller session excluded from search; cursors never exposed to model; searches serialize, exact reads parallel).

**Config keys:** compaction-basic — `thresholdRatio` (0.8), `retainRatio` (0.16) / `retainTokens` (mutually exclusive), `summarizationProvider`/`summarizationModel` (paired), `maxTokens` (8192), `compactionRetries` (1), `maxOverflowRetries` (1), `auto` (true), per-route `modelPolicies[]` overrides; pruner — `thresholdChars` (8192), `headChars` (4096), `tailChars` (1024); JSONL — `root` (required, no default by design), `packChunks` (true, ~60% smaller), `compression` (`zstd`|`none`), `preparedSessionCacheSize` (5), `writeBatchMaxDelayMs` (200); SQLite — `path`, `journalMode` (wal), `busyTimeoutMs` (5000), pins `synchronous=FULL`, POSIX ownership/mode checks; settings-file — `path`, `dshHome` (`$DSH_HOME`/`~/.dsh`), `watch` (true), `debounceMs` (100); session-title — `fallbackMaxWords`, `fallbackMaxBytes`, `maxTitleBytes` (all required); projection-cache — `writeEveryEvents`, `writeIntervalMs` (+mandatory writes at `turn/end` and disposal); telemetry-otel — `mode` (FULL/FEEDBACK_ONLY/DISABLED default), `shutdownTimeoutMillis` (3000), verbatim `exporter`/`processor`, anonymous `user.id` file; session-query-sqlite — `openAt: startup|first-search|never`; tool-session-query — `maxSearchResults` (100), `searchTimeoutMs` (30000); tool-todo — `allowParallelInProgress` (required, no default); plan-mode — `section` (required); tool-goal — `blockedAfterConsecutiveRounds`.

**Behaviors:** fork/resume via `seed` + `seedLength` + `session/end-seed` boundary event; `readFrom(id, fromSeq)` watermark reads for projection caches; `readRaw` verbatim artifact reads (JSONL yes, SQLite no, gated by `supportsRawArtifacts`); lazy materialization (never-appended sessions leave nothing on disk); title `rename()` pins against automatic retitling until explicit `refresh`; title LLM requests logged as `session/title-llm-request` with `purpose: 'session-title'` (DeepSeek adapter disables thinking); telemetry redact waterfall (`sessionTelemetry/record`, ships no rules, fail-closed on throwing listener), chunk elision (first chunk per step only), `(session.id, event.seq)` receiver dedupe; workspace one-time bootstrap grouping persisted sessions by cwd, pending-mutation marker for two-write atomicity, delete leaves logs "Ungrouped"; FTS5 queries treated as literal data (no operator injection), predicate budgets (14/13), TEMP live-row shadow over durable base; settings `applies: live|restart` UI hint; `SettingsConflictError` on stale revision; storage backends checked by a shared conformance suite (`packages/storage/storage/tests/contract.ts`).

## 4. PATTERNS WORTH STEALING

1. **Append-only log + surface `replace` op** — compaction shrinks model context without rewriting history; `sourceEventSeqs` keeps shadowed events auditable and searchable (`surface: current|shadowed|log-only` filter in session-query). See `docs/subsystems/session.md`.
2. **Lock-as-log-events** (`compaction/start`/`end` bracketing): crash mid-compaction leaves a *detectable orphaned lock*, and `session/end-seed` disambiguates stale brackets from prior lifecycles. No external lock state.
3. **Synthetic-close crash recovery** — never truncate an interrupted turn; balance it with `turn/end {interrupted}` + `TOOL_OUTCOME_UNKNOWN` results that tell the model to verify side effects (`session-checkpoint-policy/README.md`).
4. **Cheap opaque revisions** (`listSnapshots`) so read models and search indexes reconcile without full-log parses (`packages/session/session-persistence/src/revision.ts`).
5. **Spill policy as post-execute wrapper** — bounded inline output is a composable deployment choice, not per-tool logic; locator is branded/opaque with a backend-supplied `retrievalHint` (`packages/spill/spill/src/types.ts`).
6. **Deterministic pruner before LLM summarization** — free token recovery, with `compaction/prune` shadow-price events so token accounting stays pure (`compaction-tool-result-pruner/src/index.ts`).
7. **Projection registry**: "framework drives, domain computes" — pure sync folds, `Object.is` change gating, `stateVersion`-invalidated cache that is "stale but never wrong" (`packages/session/session-projection/README.md`).
8. **Redaction-aware settings wire**: path-op writes so redacted clients can't destroy secrets; `expectedRevision` optimistic concurrency; YAML comment-preserving leaf diffs (`packages/settings/settings-file/README.md`).
9. **Invariant companion plugins** — every package ships `src/invariant.ts` registering runtime cross-checks with a central `ctx.invariants` service.
10. **Reconstructability discipline** — `request/header`, `compaction/summary`, `session/title-llm-request` log full request envelopes so every model call is reproducible from log + code.
11. **Consent-gated telemetry** (`FEEDBACK_ONLY`): nothing leaves the process until a `feedback/record` event releases the exact stored prefix; the disclosure vocabulary lives in the seam so any backend can report policy.
12. **Chunk-run packing** (`packChunkRuns`): ≥3 consecutive same-block deltas pack into one row with delta-encoded seq/time, losslessly; reading is layout-blind (~60% log shrink).
