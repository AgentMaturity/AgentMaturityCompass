# DeepSeek Harness (DSH) — Engineering-Process Exploration

## 1. PACKAGE PURPOSES
- `packages/` (50+ groups, `packages/<group>/<pkg>` → `@deepseek-ai/dsh-<pkg>`): plugin-based agent harness on vendored Cordis — core (session/tools/agent-loop), api (Typert RPC gateway/BFF), typert (type-graph generator), llm, shell, subprocess, terminal, fs, lsp, skill, web, compaction, context, subagent, bundle, workflow, todo, plan, preset, guard, self-modification, hooks, session, identity, settings, credentials, acp, interaction, boot, sdk, examples, experimental, test-support, util, sandbox, e2b, goal, mcp, session-query, code-runtime, spill, storage, jobs, feedback, schedule, workspace, runtime-diagnostics, extensions.
- `vendor/`: vendored Cordis framework forks (cordis, cosmokit, schemastery, loader, hmr, timer, group, include, logger-console), rescoped via `scripts/rescope-vendor.ts`.
- `apps/cli` (owns `dsh` bin), `apps/web` (web frontend + huge e2e/snapshot lane); `examples/` (runnable cordis.yml leaves; workspace member for dependency resolution only); `python/sdk` + `python/sdk-runtime` (Python SDK + single-exe Node runtime); `native/landlock-run` (Landlock sandbox launcher); `website/` (VitePress bilingual doc projection); `scripts/` (178 files: gates + generators, each with its own `.spec.ts`); `.agents/notes` (agent-written RFC/decision records with lifecycle dirs proposed/implemented/rejected/archived) and `.agents/skills` (repo-specific agent skills).

## 2. KEY MECHANISMS
- **Gate runner** (`scripts/run-gates.ts`, 967 lines): a validated DAG scheduler for quality gates. Each `Gate` has `needs` (must pass), `after` (must settle), `env`, `allowFailure`, `streamOutput`. Named aggregates (`ci-primary`, `ci-static`, `ci-coverage`, `ci-snapshot`, `ci-artifacts`, `ci-consumers`, `ci-windows-{blocking,complete,observational}`, `node-compat`, `check-all`, `doc-sync`) are composed from shared gate-list functions. Cycle detection, skip-propagation on failed deps, bounded concurrency (`DSH_GATE_CONCURRENCY`, mode-aware defaults), shell-free spawning via `process.execPath + npm_execpath` (Windows-safe).
- **Two-face tsconfig** (`tsconfig.json` solution file, `tsconfig.host.json`, `tsconfig.client.json`, bases): host and client both merge Cordis `Context` under the same keys, so one ts.Program can never see both. Test files pick a face by suffix (`*.client.spec.ts` vs `*.host.spec.ts`). `scripts/project-reference-faces.ts` validates face isolation across the reference graph. `tsdown.config.ts` builds per face via `--env.DSH_BUILD_FACE host|client`, host face running the Typert plugin.
- **Build profiles** (`scripts/build.ts` + `client-build-environment.ts`): `--profile official` pins public `DSH_CLIENT_*` env values (title, profile, 7-char commit hash), deletes/rewrites `.dsh-build/client-build-environment.json` — a record with SHA-256 digest over sorted client artifacts, so downstream gates can prove which environment produced the bits.
- **Coverage**: per-file **100% statements/branches/functions/lines** thresholds (`vitest.config.ts`), with surgical, commented exclusions (Windows-only src, child-process entries, TODO(gui) UI files). `scripts/coverage-exempt.ts` lists heavy suites run **uninstrumented in a parallel gate** (membership rule: every measured file they touch is already covered elsewhere). `scripts/coverage-partitions.ts` + `run-coverage-partitions.ts` shard instrumented coverage into N single-worker Vitest processes (`DSH_COVERAGE_PARTITIONS`) producing v8 blobs merged into one thresholded report; custom CJS reporter `coverage-uncovered-locations.cjs` prints exact `path:line:col` for every miss.
- **Snapshot system** (`vitest.snapshot.config.ts`, `packages/test-support/llm-replay`): three modes via `DSH_SNAPSHOT` — `replay` (keyless default; boots the real agent from recorded `session.jsonl`, diffs assembled requests/transcripts), `record` (real API, loads `.env`), `refresh` (replays committed scripts, rewrites goldens). The fixture *is* the persisted session log; replay reconstructs each `stream()` call by grouping `assistant/chunk` events by `(turn,step)`. Sidecar `replay.override.json` patches non-reconstructable failures (pre-chunk throw, hang with `readyFile` marker); `{{fromRequest:<regex>}}` placeholders resolve dynamic ids against the live request. Nested subagents get per-session scripts (`session.1.jsonl`…) bound by first-call order. Replay parallel, record/refresh serial.
- **Windows-via-Wine** (`scripts/wine-windows-gates.sh`): the *required* PR Windows signal runs real checksum-verified win-x64 Node under Wine on hosted Linux — snapshots the git tree to scratch, appends Wine-only pnpm overrides (`nodeLinker: hoisted`, `supportedArchitectures` win32/x64) to the snapshot's workspace file, retries a known pnpm rename race (pnpm/pnpm#12880), runs build + VitePress site concurrently with per-log failure reporting. Native Windows (`windows-native`, 16-core) runs the complete gate inventory non-blocking; observational gates get `allowFailure: true`.
- **CI failover**: repo variables `DSH_CI_FAILOVER_LINUX/WINDOWS=selfhosted` retarget required jobs onto in-house VM pools via `runs-on` expressions (Dependabot excluded); master pushes run **hot-standby drills** (`serial-linux-selfhosted`, `serial-windows`) — complete unsharded aggregates with all concurrency knobs at 1 — continuously proving takeover readiness. `all-checks-passed` aggregates every blocking job with `if: always()` (skipped required check counts as passing on GitHub).
- **Doc verification** (`docSyncLeafGates`, ~28 gates): `doc-typecheck.ts` compiles every markdown ` ```ts ` fence against the workspace API (`ignore-check` counted as opt-out ratio; catalog/type-equiv fences delegated to owning gates; byte-identical `.zh.md` reuse the sibling's check); `verify-md-wrap.ts` rejects hard-wrapped prose via mdast paragraph analysis; `verify-md-links.ts` resolves relative links *and* heading-slug anchors; `verify-doc-site-fragments.ts` re-validates fragments against VitePress-emitted HTML (different slugger); `verify-type-equiv.ts` diffs doc code blocks against real source declarations via `type-equiv.manifest.json`; `verify-doc-budgets.ts` enforces per-doc word ceilings that ratchet down (`doc-budgets.manifest.json`); translation pairing records git blob hashes per EN/ZH pair (`*.i18n.yaml` sidecars) with `--write/--cached/--list` and a merge-conflict resolver.
- **Issue automation** (`.github/issue-management/policy.mjs`, 706 lines + 413-line test, bilingual errors): validates Issue type/priority/status/labels against a GitHub Project, enforces body length in "visible units" (Han chars + Latin tokens, `<details>` content excluded), plans status transitions from events (assign→In progress, review→In review, close→Done/No action), audits via marker comment, reserves retired label aliases; runs from *trusted default-branch checkout* with a GitHub App token (`issue-lifecycle.yml`, `issue-policy.yml`).
- **Git hooks** (`lefthook.yml`): staged-only lint with autofix (`stage_fixed: true`), translation-pairing check on staged `.i18n.yaml`, third-party-notices *regenerated* (not rejected) when any manifest changes, whitespace check, vendor-manifest guard; pre-push = typecheck only ("CI owns the full matrix").

## 4. PATTERNS WORTH STEALING
- **In-process gate DAG over CI-native steps** (`scripts/run-gates.ts`): package scripts own public names; the runner owns dependency graphs, concurrency, and diagnostics — portable across GitHub/GitLab/local, testable (`run-gates.spec.ts` injects executors).
- **Session-log-as-fixture replay** (`packages/test-support/llm-replay`): record once against the real API, replay the *persisted event log* keylessly; override sidecars + request-regex placeholders handle nondeterminism. Ideal for any agent-infrastructure product.
- **Generator `--check` duality**: every generated doc/catalog has one script with `gen-*` and `verify-*` entry points — drift is impossible to merge.
- **Docs as typechecked code**: `doc-typecheck.ts` + `verify-type-equiv.ts` compile doc fences against the live API and pin doc-quoted declarations to source symbols via manifest.
- **Agent Notes** (`.agents/notes/AGENTS.md`): agent-authored RFCs with lifecycle folders, dated filenames, format/classification/archive *gates* (`verify-agent-note-*`), and supersession protocol; CI comments cite notes by path.
- **Wine as required Windows signal + native Windows as observational**, plus writer-flippable failover variables and continuously-drilled self-hosted standbys.
- **Coverage-exempt-with-invariant**: heavy suites still run (correctness preserved) but skip v8 instrumentation, with an explicit membership rule making the exemption provably threshold-neutral (`scripts/coverage-exempt.ts`).
- **Doc word-budget ratchet** (`verify-doc-budgets.ts`) and md-wrap/anchor gates keep prose agent-editable and diff-stable.
- **Trusted-checkout policy bots**: issue automation always executes default-branch code with an App token, never PR code.
- **Fail-loud env parsing everywhere**: every knob rejects malformed values instead of silently defaulting.
