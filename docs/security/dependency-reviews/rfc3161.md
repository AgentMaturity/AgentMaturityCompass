# Dependency review: RFC 3161 timestamps (P1-25)

**Status:** no dependency added. Decision pending (needs Sid).

## What the code needs

Encode a `TimeStampReq`, parse a `TimeStampResp`, verify a CMS SignedData signature with its signed attributes, read ESSCertID and ESSCertIDv2, and check an X.509 path to a pinned anchor.

## What this branch does instead

P1-25 asks for Sid's approval before any package is added, so this branch implements the subset on Node's built-in `crypto` (`verify`, `X509Certificate`) and a 120-line strict DER reader and writer (`src/time/der.ts`). The reader accepts only definite, minimal lengths and single-byte tags, bounds every read by its parent, refuses trailing bytes, and the verifier caps tokens at 64 KiB. It supports RSA PKCS #1 v1.5, ECDSA and Ed25519 signatures with SHA-256, SHA-384 or SHA-512, and refuses SHA-1 signatures and RSA-PSS.

Trade-off: hand-written ASN.1 parsing is a known source of defects. The code is small and refuses rather than guesses, but it has not had the scrutiny of a maintained library. RSA-PSS, name constraints and policy constraints are not supported.

## Recommendation

Keep the built-in implementation unless review finds a gap it cannot close in a few lines; if a library is wanted, use `pkijs` with `asn1js` and keep `src/time/verifyTimestamp.ts` as the single entry point so the swap stays local.
